# P0 비주얼 기술 검증 (임시)

`design_ssot/TECH_STACK.md` §P0 비주얼 기술 검증용 시험 코드다. **버릴 코드**이고, 실제 레이스 시뮬레이터가 아니다(주행은 화면 확인용 가짜).

- 스택: Vite + TypeScript + Phaser 3.90 (Phaser 물리 미사용)
- 아트: 코드로 그린 임시 픽셀 텍스처(외부 에셋 없음)

## 실행

```bash
npm install
npm run dev
```

같은 와이파이의 폰에서 `http://<PC IP>:5173`으로 열 수 있다(`vite --host`).

## 확인할 것

| 화면 | 조작 | 보는 것 |
|---|---|---|
| 레이스 | `카메라`: 내 차 → 선두 → 전체 | 작은 화면에서 내 차 · 선두 그룹 · 순위 변동이 읽히는가 |
| 레이스 | `시점`: 아이소 ↔ 탑다운 | 어느 시점이 10대를 더 잘 읽게 하는가 (OPEN O-007) |
| 레이스 | `같은 시드` / `새 시드` | 같은 시드면 같은 레이스가 재생되는가 |
| 차고 | `강화` | 아이소 차고 · 정비사 깊이 정렬 · 강화 연출 |
| 공통 | 우상단 FPS | 실기기에서 프레임 유지 |
