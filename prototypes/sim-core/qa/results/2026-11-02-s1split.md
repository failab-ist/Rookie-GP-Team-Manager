# S1 실패 원인 분리 측정 (측정용 옵션, 기본값 그대로)

s1cap 기준 설정과 같은 조건: L-B 3트랙, MOTIF_ALL(더티 에어 3, 부스트 4), 참가 10대, 출발 순서 10가지 순환 × 50시드 = 설정당 1500레이스. 측정용 옵션 carWidth · laneWidth(기본 config 값)를 하나씩만 바꿨다.

- 기준선: 차 폭 3, 차선 폭 4. 차 폭 1.9: 차선 폭 4 그대로, 상한 해제 옆 간격도 차 폭을 따라 1.9(OT-2 정의 "옆 간격이 차 폭 이상", 옵션을 따로 주지 않으면 차 폭). 차선 폭 5: 차 폭 3, 차선 수 3 그대로(차선 변경 시간이 1.0 s → 1.25 s, 해제는 진행 0.6에서).
- 회귀: 옵션을 주지 않은 결과가 지난 코드와 같다(`node qa/s1cap.ts fingerprint` 해시 017c289cd765f1e8 / e569234cd6fc1829, 78fbe58과 같음). 테스트 33개 통과.
- 정의(시간축, 차선 변경 완료, 제동 시작, 슬립스트림으로 줄인 거리)는 `qa/s1split.ts` 머리 주석. 제동 시작 = 차선 변경 완료 뒤 처음으로 공격 차 속도가 줄고 그 틱 막힘 상한 표시가 없는 틱.
