# P-1 늦게 빠지기 단독 측정 (디렉터 결정 AG-P068 A, 측정용 옵션, 기본값 그대로)

규칙 P-1(측정용 옵션 `lateOut` = T_out, 0 = 꺼짐이 기본): 직선에서 정식 시도 조건이 되어도(같은 차선 앞차 간격 ≤ TRY_GAP, 옆 차선 빈 창 있음) 다음 코너 제동 시작점까지 남은 시간 (남은 거리 ÷ 현재 속도)이 T_out보다 길면 같은 차선에 머문다. T_out 이하가 된 판단 틱에 지금과 같은 방식으로 시작한다. 제동 시작점 = 직선 끝 − (v² − 코너 한계²) / (2 a_brk), 코너 한계는 그 틱 능력치(더티 에어 포함). 옆 차선이 차 있으면 지금 규칙 그대로(시도 없음). 코너 구간과 다음 구간이 직선인 경우는 바꾸지 않는다. 머물기 시작한 판단 틱에 판정 기록 종류 10(lateHold)을 남긴다. 관성(M-1) · 늦은 제동(B-1)은 넣지 않았다.

- 조건: 현재 기본값(차 폭 1.9), L-B 3트랙, MOTIF_ALL, 참가 10대, 출발 순서 10가지 순환 × 50시드 = 설정당 1500레이스. 기준선 = 스위치 꺼짐(= `carwidth.md`의 1.9u 결과와 같은 설정).
- 회귀: 스위치를 끈 결과가 HEAD(b8e86e4)와 같다. `node qa/s1cap.ts fingerprint` = 기본 옵션 0ad1b4259072765d, FINAL 순환 52499292f74c2295 (HEAD · 변경 후 같음). 테스트 34개 통과.
- 종료 조건: 어느 T_out에서도 S1 성공률이 기준선(조정용 2.4%)보다 오르지 않았다(1.2 / 1.5 / 1.6 / 1.8%). 지시대로 더 조정하지 않았다.
- 표 1~5는 `s1split.md`와 같은 정의, 표 6 · 7과 몫 표를 더했다(`qa/s1split.ts`, `qa/motif.ts share`).
