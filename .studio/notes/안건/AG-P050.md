# AG-P050 서킷 지도 판독 방식

개발 세션이 지도 PDF를 받아 두고 다음 할 일을 묻습니다. 코너 좌우를 어떻게 판독할지 골라 주세요.

세 PDF는 qa/sources/fia_2025/에 저장됐습니다. 프로듀서 쪽은 PDF 렌더링 도구가 없어 지도를 못 열고, PNG라면 읽을 수 있습니다. 헝가리는 실제 코너가 16개(1~14, 1A, 12A)이고 우리 M2는 8개라, 데이터 입력에는 코너 대응(Q-85)과 AG-P049 결정이 먼저 필요합니다.

## 선택지
- A. 개발 세션 판독과 프로듀서 PNG 판독 교차. 장점: 두 쪽이 따로 읽어 맞춰 보니 판독 실수를 잡기 쉬움 / 단점: PNG 렌더링과 비교 단계가 하나 더 듦
- B. 개발 세션 판독만. 장점: 가장 빠름 / 단점: 한 쪽만 읽어 좌우를 잘못 읽어도 거를 장치가 없음
- C. 바로 데이터 입력과 재측정. 장점: 홀짝 쏠림 재측정 결과를 가장 빨리 봄 / 단점: AG-P049와 코너 대응이 안 정해져 우리 코너에 방향을 임의로 배정하게 됨

## 결정
A. 개발 세션 판독과 프로듀서 PNG 판독 교차 (추천은 A: 좌우 판독은 한 번 틀리면 재측정이 다 틀어집니다. 비용이 작으니 두 쪽이 따로 읽는 편이 안전합니다.)
