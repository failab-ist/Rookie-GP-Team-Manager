# AG-P021 프로토 코드 착수 방식

세 초안이 나오면 코드를 어디서 어떤 순서로 짤지 골라 주세요. 코드 폴더 쓰기 허락도 이 결정에 들어갑니다.

지금 작업은 문서 폴더에만 쓸 수 있다. TECH_STACK은 시뮬레이터를 화면과 분리된 TS 모듈로 정했다. 화면 시험판 prototypes/p0-visual이 이미 있다. 초안 수치는 가안이며 프로토 시험값으로만 쓴다.

## 선택지
- A. 시뮬레이터 먼저, 그다음 화면 연결. 장점: TECH_STACK 경계와 맞고 자동 QA로 빨리 판정 / 단점: 처음 며칠은 화면 없이 숫자로만 확인
- B. p0-visual 안에 바로 구현. 장점: 처음부터 화면으로 볼 수 있음 / 단점: 화면과 계산이 엉켜 서버 재사용과 자동 QA가 어려움
- C. 초안 검토 후 다시 정함. 장점: 문서를 보고 범위를 조정할 수 있음 / 단점: 착수가 늦어짐

## 결정
A. 시뮬레이터 먼저, 그다음 화면 연결 (추천은 A: 같은 시뮬레이터를 서버와 앱이 함께 쓰는 구조라 처음부터 분리해야 다시 짜는 일이 없다.)
