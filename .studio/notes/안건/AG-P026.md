# AG-P026 가속력이 거의 효과 없는 문제 (Q-46)

가속 +1이 0.2~0.5%만 효과가 있어 시험에서 떨어졌습니다. 공식을 고칠지 시험 기준을 바꿀지 골라 주세요.

다른 능력치는 +1에 맡은 구간이 4% 좋아지는데 가속은 공식 구조상 2%를 넘지 못한다. 시험 기준만 바꾸면 플레이어에게 가속은 쓸모없는 능력치로 남는다. 초안은 Δ=2 시험, 합격선 낮추기, 1층 제외를 선택지로 적었다.

## 선택지
- A. 가속 공식을 고쳐 효과를 키움. 장점: 능력치 4개의 1점 가치가 비슷해짐 / 단점: 초안 공식 수정과 재계산 필요
- B. 가속만 +2로 시험. 장점: 공식을 안 건드림 / 단점: 게임 안에서 가속이 약한 건 그대로
- C. 1층 합격선 없이 순위와 영상으로만 판정. 장점: 추월이 생기면 가속 가치가 오를 수 있음 / 단점: 약한 능력치를 늦게 발견할 위험

## 결정
A. 가속 공식을 고쳐 효과를 키움 (추천은 A: 시험 기준을 바꿔도 플레이어가 가속을 올릴 이유가 없는 건 그대로다. 문제는 시험이 아니라 공식에 있다.)
