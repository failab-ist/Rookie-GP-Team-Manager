# AG-P007 레이스 화면 연출 방식

레이스를 TV 중계처럼 자동으로 장면을 바꿔 보여 줄지 골라 주세요. 카메라 각도는 그다음에 실측으로 정합니다.

지금 O-007은 각도만 다루고 어떤 장면을 언제 보여 줄지는 비어 있다. 비슷한 경영형 레이싱 게임은 자동 장면 전환, 늘 떠 있는 순위표, 내 차 고정 버튼을 함께 쓰는 경우가 많다(영상 확인 필요).

## 선택지
- A. 자동 중계와 내 차 고정 버튼. 장점: 보기만 해도 재미있는 장면이 나옴, 경쟁작과 같은 문법 / 단점: 시뮬레이터 사건 기록과 전환 규칙 작업 필요
- B. 플레이어가 버튼으로 직접 전환. 장점: 규칙이 단순하고 만들기 쉬움 / 단점: 자동 레이스인데 손이 가고 명장면을 놓침
- C. 내 차 화면 하나와 경기 뒤 하이라이트. 장점: 화면이 가장 차분함 / 단점: 경기 중 다른 차 싸움이 안 보임

## 결정
A. 자동 중계와 내 차 고정 버튼 (추천은 A: 자동 레이스는 지켜보는 재미가 핵심이다. 필요한 사건 기록은 결과 이유 카드와 패시브 연출에도 쓰여서 추가 비용이 작다.)
