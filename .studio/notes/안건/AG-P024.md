# AG-P024 정점 뒤 코너 한계 속도가 풀리는 방식

지금 초안은 코너 한계 속도가 끝까지 같아서 탈출 가속이 거의 생기지 않습니다. 정점 뒤에 한계가 풀리게 할지 골라 주세요.

초안은 정점 이후 가속을 허용했지만 한계 속도가 코너 내내 같다. 브레이크로 이미 한계까지 줄여 들어오므로 더 올릴 여유가 없고, 결과는 옛 규칙과 같다. 실제 주행은 정점 뒤 코너가 펴지며 버틸 수 있는 속도가 오른다.

## 선택지
- A. 그대로 둠(한계 일정). 장점: 지금 초안으로 바로 개발 / 단점: 탈출 가속 장면이 거의 안 나옴
- B. 정점 뒤 한계가 점점 풀림. 장점: 탈출 가속이 보이고 가속, 접지 차이가 드러남 / 단점: 트랙 표 값이 다시 바뀌어 개발 중 실측으로 맞춰야 함

## 결정
B. 정점 뒤 한계가 점점 풀림 (추천은 B: 디렉터가 원한 실제 F1식 탈출 가속은 B여야 나온다. 손계산을 다시 하기보다 시뮬레이터 실측으로 표를 채우는 편이 빠르다.)
