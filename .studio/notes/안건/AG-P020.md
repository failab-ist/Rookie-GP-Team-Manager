# AG-P020 O-002 차량 모델, 트랙 3종, 프로토 합격 기준 초안

차량 4능력치의 주행 동작, 프로토 트랙 3종과 구간 데이터 형식, 차 2종 시험값, 프로토 합격 기준을 한 문서로 쓴다. AG-P017, P018, P019 결정을 따르고, 합격 기준은 결과를 보기 전에 고정할 수

허용 경로: design_ssot/drafts/, 완료 기준: 접지와 제동은 작동 시점으로 분리(AG-P017 A): 제동은 코너 진입 전 감속, 접지는 코너 안 한계 속도 / 4능력치마다 반응해야 할 구간(직선, 진입, 코너 안, 탈출)을 명시 / 차 2종은 4능력치 총합 동일, 분포만 다른 프로토 시험값(AG-P018 A), 확정 규칙 아님을 명시 / 트랙 3종은 구간 비율이 다르되 한 능력치만 쓰는 코너는 두지 않음 / 구간 데이터 형식: 종류, 길이, 휘는 정도, 폭, 추월 가능 표시 / 합격 기준 3층: 능력치 하나 바꾼 

## 선택지
- A. 작업으로 올리기. 장점: 작업 탭에서 종류를 고르고 시작
- B. 다시 상의. 장점: 범위를 더 다듬음
