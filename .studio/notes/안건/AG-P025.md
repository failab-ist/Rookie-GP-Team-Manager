# AG-P025 10대 상호작용 모델 초안 (O-001)

차끼리 영향을 주는 규칙을 설계한다. 차선과 횡 위치, 앞차에 막혔을 때 뒤차 속도, 추월 시도와 성공 조건, 접촉과 손실, 출발 직후 혼전, 슬립스트림 여부를 정하고, 레이서 3능력치와 패시브 3종이 이 규칙 위에

허용 경로: design_ssot/drafts/, 완료 기준: 레이서 능력치 방식과 패시브 방식은 디렉터 결정을 따르고, 결정 전이면 선택지로 남김 / 차선, 막힘, 추월, 접촉 규칙마다 공식, 변수표, 범위, 계산 예시, 퇴화 결과 / 모든 판정은 시드 난수만 쓰고 같은 입력이면 같은 결과 / 자동 중계 초안이 요구하는 사건 기록(추월, 접촉, 패시브 발동, 반대급부)과 항목 일치 / 가속 +1의 구간 효과가 다른 능력치와 비슷한 크기가 되는 변환식 선택지(가속 카드가 A일 때) / 2층 시험을 상호작용이 있는 조건으로 다시 정의
