# AG-P032 추월 0건 원인 확인 순서

추월이 막히는 원인이 물리인지 추월 규칙 버그인지 아직 모릅니다. 확인 순서를 골라 주세요.

코드를 보면 차선을 바꾸는 동안에도 원래 차선 앞차에 속도가 묶이고(sim.ts:147-149, 207-210), 바꾸고 나면 슬립스트림이 사라진다(:395-400). 이 경우 슬립스트림을 키워도 안 풀릴 수 있다. 가속과 제동이 약한 문제는 차 한 대로 달려도 나오므로 따로 잰다.

## 선택지
- A. 2대 시험 먼저, 하나씩 비교. 장점: 버그인지 물리인지 확실히 가려짐 / 단점: 실험이 한 번 더 늘어남
- B. 슬립스트림만 바로 키움. 장점: 계수 하나라 가장 빠름 / 단점: 차선 변경 중 속도 묶임이 원인이면 안 풀림
- C. 제동 추월과 가속 둔화를 함께. 장점: 근본 해결에 가장 가까울 수 있음 / 단점: 둘을 같이 바꿔 무엇이 효과였는지 모름

## 결정
A. 2대 시험 먼저, 하나씩 비교 (추천은 A: 코드에서 속도 묶임이 확인돼 규칙 문제일 수 있다. 진단이 세 번 틀렸으니 이번에는 하나씩 가려야 한다.)
