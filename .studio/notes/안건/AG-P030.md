# AG-P030 실제 서킷 모티브 트랙 3종 초안

실제 서킷의 코너 순서, 직선과 코너 비율, 헤어핀 뒤 긴 직선 구조를 모티브로 프로토 트랙 3종(직선형, 코너형, 균형형)을 다시 설계한다. 실측에서 나온 두 문제(추월 0건, 가속과 제동이 순위에 거의 영향 없음

허용 경로: design_ssot/drafts/, 완료 기준: 트랙 유형마다 모티브 서킷 후보 2개 이상과 고른 이유, 실제 서킷과 달라진 점을 적는다 / 대표 코너 6~10개로 줄이고 붙은 코너를 어떻게 묶었는지 적는다 / 1바퀴 길이 축소안을 3개 이상(예: 약 15초, 25초, 40초) 두고 각 안의 3랩 경기 길이를 손계산한다. 하나로 정하지 않는다 / 트랙마다 추월 가능 직선이 2곳 이상이고, 그 직선을 지나는 시간이 현재 차선 변경 시간(config 값)의 3배 이상이다 / 헤어핀이나 느린 코너 뒤 긴 직선을 트랙마다 1
