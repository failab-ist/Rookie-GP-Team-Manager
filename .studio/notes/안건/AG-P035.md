# AG-P035 모티브 트랙 초안에 코너 방향과 부스트 구간 추가

AG-P034에서 쓴 모티브 트랙 3종 초안에 두 칸을 더한다. 코너마다 도는 방향(왼쪽, 오른쪽)을 적고, 트랙마다 추격 부스트 구간 1~2곳을 정한다. 추월 규칙의 코너 우선권과 안쪽 차선, 부스트 구간에 쓰인다

허용 경로: design_ssot/drafts/, 완료 기준: 모든 코너에 방향을 적고, 모티브 서킷의 실제 방향을 따랐는지 바꿨는지 이유와 함께 적는다 / 코너마다 안쪽 차선 번호를 적는다(3차선 기준, 차선 0~2) / 트랙마다 부스트 구간 1~2곳을 정하고 위치, 감지 지점, 고른 이유(느린 코너 뒤 긴 직선 등)를 적는다. 모티브 서킷의 실제 DRS 구간을 참고했는지 적는다 / 부스트 보너스 크기는 가안 범위로만 두고 하나로 정하지 않는다 / 게임 안에서 부를 이름은 가상 이름(예: 추격 부스트)으로 하고 DRS는 참고 설명

- B. 다시 상의. 장점: 범위를 더 다듬음
