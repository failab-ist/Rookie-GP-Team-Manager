# AG-P010 앱에서 레이스 재계산 안 (CONFLICT)

가이드의 '앱이 시드로 다시 계산' 안은 TECH_STACK의 서버 계산, 앱 재생 원칙과 충돌합니다. 기각할지 골라 주세요.

TECH_STACK은 서버가 계산하고 앱은 기록을 재생하도록 정했다. 앱 재계산은 기기마다 소수점 결과가 달라 화면과 결과가 어긋날 위험이 있다. 남는 일은 기록 상세도와 보관 방식이며, 경기 하나의 용량부터 잰다.

## 선택지
- A. 기각, 서버 기록 재생 유지. 장점: 기기마다 결과가 같고 기준 문서와 맞음 / 단점: 기록 용량과 다운로드 비용을 따로 재야 함
- B. 앱 재계산을 후보로 남김. 장점: 서버 비용이 줄 가능성 / 단점: 기기별 계산 차이 위험, TECH_STACK 변경 필요

## 결정
A. 기각, 서버 기록 재생 유지 (추천은 A: 이미 정한 원칙이고, 결과가 기기마다 달라지면 리그 신뢰가 무너진다. 비용은 실측으로 따진다.)
