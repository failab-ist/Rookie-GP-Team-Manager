# AG-L003 첫날 공백을 메우는 방식

입문전을 매일 00시 NPC 프렙 리그로 구체화할지 결정.

정규 리그는 다음 월요일 편성이라 가입 요일에 따라 최대 6일 대기. GDD §5.7에 NPC 입문전은 이미 있음. 보고서의 '5~6일 깡통'은 과장.

## 선택지
- A. 입문전만. 장점: 추가 작업 없음 / 단점: 매일 돌아올 이유 약함
- B. 프렙 리그(매일 00시). 장점: 정규 리그 리듬 미리 체험 / 단점: NPC 조 운영 규칙 필요
- C. B + 티켓 없는 스파링. 장점: 첫날 밀도 최대 / 단점: 범위 증가, 축소판과 충돌

## 결정
보류 (추천은 B: 축소판 범위 안에서 첫 주 공백을 메운다. C는 나중.)
