# AG-P039 접촉 규칙: 차선 안 흔들림과 접촉 3종

추월의 35~40%가 접촉에서 나옵니다. 접촉 규칙을 F1식으로 바꿀지 골라 주세요.

옆 차선과의 여유가 1u인데 횡 오차는 최대 2u라서 자주 스친다(config.ts:107). 스치면 뒤에 있던 차를 순간 이동시켜 순서가 바뀐다(INT:76). 안은 평소 흔들림을 차선 안으로 제한하고, 접촉을 옆, 차선 변경 중, 뒤 추돌로 나눠 옆 접촉은 속도 손실만 주며, 원인 제공자를 기록한다. 적정 접촉 수는 실측 뒤 정한다.

## 선택지
- A. 2대 시험 뒤 CT-1, 3, 4, 5를 하나씩. 장점: 원인을 확인하고 효과를 하나씩 가림 / 단점: 실험이 한 번 더 필요
- B. 옆 접촉 순간 이동만 없앰. 장점: 가장 작은 수정 / 단점: 스침 자체는 그대로 많아 속도 손실이 쌓임

## 결정
A. 2대 시험 뒤 CT-1, 3, 4, 5를 하나씩 (추천은 A: 접촉이 추월을 만드는 동안에는 능력치 효과가 가려진다. 흔들림과 처리 둘 다 원인이라 둘 다 봐야 한다.)
