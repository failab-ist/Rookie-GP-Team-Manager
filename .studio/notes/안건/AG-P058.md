# AG-P058 차선 번호 규약 확정 (Q-78)

코너 방향 입력에 쓴 차선 규약 A(왼쪽 끝 0번)를 정식으로 둘지 정해 주세요.

코너 방향 입력과 재측정은 규약 A(L 코너 안쪽 0번, R 코너 안쪽 2번)로 했습니다. 출발 그리드 A열은 0번, B열은 2번 차선입니다. DIRECTION 초안의 Q-78은 아직 열려 있습니다.

## 선택지
- A. 규약 A 확정 (왼쪽 끝 0번). 장점: 코드와 데이터와 측정이 모두 이 규약이라 바꿀 것이 없음 / 단점: 없음에 가까움. 나중에 화면 좌우와 맞출 때 한 번 확인 필요
- B. 규약 B (반대). 장점: 화면 좌표계가 반대일 경우 맞추기 쉬울 수 있음 / 단점: 코드와 데이터를 뒤집고 다시 측정해야 함

## 결정
A. 규약 A 확정 (왼쪽 끝 0번) (추천은 A: 이미 A로 구현하고 측정까지 마쳤습니다. 바꿀 이유가 생기면 그때 뒤집어도 됩니다.)
