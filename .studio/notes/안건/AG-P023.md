# AG-P023 코너 안에서 가속하는 방식 (Q-42)

차가 코너를 돌면서 언제부터 가속할 수 있는지 골라 주세요. 디렉터 의견은 C(정점 이후 가속)에 가깝습니다.

코너는 진입(브레이크), 정점(가장 느림), 탈출로 나뉜다. 초안은 코너 안 가속을 막아 두었다. 실제 F1은 정점 이후 돌면서 가속한다. B나 C를 고르면 초안의 트랙 표 숫자를 다시 계산해야 한다.

## 선택지
- A. 코너 안 가속 없음(초안대로). 장점: 계산이 가장 단순하고 지금 바로 개발 가능 / 단점: 실제 주행과 다르고 탈출 가속 장면이 안 나옴
- B. 코너 어디서든 가속. 장점: 규칙이 단순함 / 단점: 브레이크와 가속이 같은 코너 안에서 섞여 역할이 흐려짐
- C. 정점 이후부터 가속(실제 F1). 장점: 탈출 싸움이 보이고 제동, 접지, 가속 역할이 또렷함 / 단점: 코너를 세 토막으로 계산해 초안 손질이 가장 큼

## 결정
C. 정점 이후부터 가속(실제 F1) (추천은 C: 디렉터가 말한 실제 주행과 맞고, 코너 탈출이 좋은 차가 직선에서 앞서는 장면이 능력치 차이를 보여 준다.)
