# AG-P046 고증 참고 범위

실제 F1을 어디까지 따를지 정해 주세요. 가속 곡선과 속도별 제동 실험의 기준이 됩니다.

가속 곡선(구동력과 공기저항)과 속도별 제동(다운포스) 실험을 고증 근거로 진행하려 합니다. F1 규정은 시대마다 다르고, 2026년에는 추월 보조 방식도 능동 공력과 추가 전력으로 바뀌었습니다. 서로 다른 규정이 섞이지 않게 기준이 필요합니다.

## 선택지
- A. 물리만 참고, 자료마다 연도 표기. 장점: 규정 변화에 끌려가지 않고 부스트 구간은 우리 규칙으로 유지 / 단점: 실제 레이스와 견줄 기준 시대가 없음
- B. 2022~2025 시대를 기준으로. 장점: DRS와 부스트 구간이 닮아 비교하기 쉬움 / 단점: 이미 지난 규정이라 최신 F1과 감각이 다를 수 있음
- C. 2026 규정을 기준으로. 장점: 최신 F1과 맞음 / 단점: 새 규정이라 자료가 적고 부스트 구간을 다시 설계해야 함

## 결정
A. 물리만 참고, 자료마다 연도 표기 (추천은 A: 물리는 시대와 상관없이 맞고, GPT 제안대로 연도를 남기면 규정이 섞이지 않습니다.)
