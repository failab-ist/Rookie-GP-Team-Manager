# AG-L010 숙소, 차고 꾸미기 제외 기록

GDD에 남은 숙소, 차고 꾸미기는 GAME_VISION이 배제. 제외 사실을 CHANGELOG에 남길지 결정.

GAME_VISION '하지 않을 것': 시설 운영 타이쿤 금지. SSOT가 기획서보다 우선.

## 선택지
- A. CHANGELOG에 기록. 장점: 혼선 방지 / 단점: 작업 1건
- B. GDD대로 유지 검토. 장점: 꾸미기 수익 여지 / 단점: 타이쿤 금지와 충돌

## 결정
B. GDD대로 유지 검토 (추천은 A: 이미 정한 방향의 기록 정리.)
