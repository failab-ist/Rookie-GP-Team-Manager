# AG-P031 트랙 초안 기다리는 동안 개발 세션 작업

모티브 트랙 초안이 나올 때까지 개발 세션을 쉬게 할지, 직선 길이와 차선 변경 속도 실험을 같이 돌릴지 골라 주세요.

추월 0건의 원인은 짧은 직선과 1초 걸리는 차선 변경으로 보인다. 초안(AG-P030)은 직선 시간이 차선 변경 시간의 3배 이상이어야 한다고 정했는데, 차선 변경 시간 자체가 바뀔 수 있다. 지금 트랙의 직선만 1.5배, 2배로 늘리고 v_lat 6을 섞어 재면 초안이 쓸 기준 숫자가 생긴다.

## 선택지
- A. 실험을 같이 돌림. 장점: 초안에 쓸 실측 기준이 생김, 코드 수정 작음 / 단점: 버릴 트랙으로 하는 실험이라 결과 일부는 다시 안 씀
- B. 초안이 나올 때까지 기다림. 장점: 작업이 겹치지 않음, 새 트랙으로 한 번에 잼 / 단점: 초안이 손계산만으로 직선 길이를 정해야 함

## 결정
A. 실험을 같이 돌림 (추천은 A: 직선이 몇 초면 추월이 되는지는 손계산보다 실측이 정확하다. 실험 비용이 작고 초안 품질이 올라간다.)
