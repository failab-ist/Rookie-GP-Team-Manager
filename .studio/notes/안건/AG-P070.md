# AG-P070 축척 범위

1u = 1m는 폭과 차 크기에만 먼저 쓰고, 속도와 시간은 추월 측정 뒤 단계적으로 맞추길 권합니다.

1u = 1m는 규정에서 도출되지 않는 설계 선택입니다(GPT). 1m로 읽으면 최고속도 약 450km/h, 헤어핀 약 180km/h, 제동 0.8g, 랩 1.8km라 실제 F1(약 330km/h, 70~100km/h, 4~5g, 4.3~5.4km, 프로듀서 기억)과 크게 다릅니다. 연속 가로 위치 설계(AG-P066 D)에 폭 기준이 필요합니다.

## 선택지
- A. 기하만 1m, 속도와 시간은 현행. 장점: 지난 측정을 살리고 폭 설계를 바로 시작함 / 단점: 속도와 거리 비율의 어긋남이 계속 남음
- B. 전부 1m로 맞춤. 장점: 고증에 가장 가까움 / 단점: 속도, 가속, 제동, 랩을 다시 잡아 측정이 거의 무효
- C. 기하는 1m, 속도와 시간은 단계적으로. 장점: 추월 원인을 가린 뒤 순서대로 고증에 맞춤 / 단점: 중간 단계가 길어짐

## 결정
C. 기하는 1m, 속도와 시간은 단계적으로 (추천은 C: 기하만 맞춰도 폭 설계는 시작할 수 있습니다. 추월 원인을 먼저 가린 뒤 속도와 제동을 맞춰야 원인이 섞이지 않습니다.)
