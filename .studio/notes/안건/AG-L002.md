# AG-L002 패시브, 능력치 초안을 어떻게 쓸지

액션 플랜의 패시브 3종 초안(+40% 등)을 O-003, O-004 작업에 어떻게 쓸지 결정.

초안 수치는 근거 없는 가안. 원인 로그는 TECH_STACK에 이미 있음. LOCKED: 총합 동일, 레이서당 고유 패시브 1개.

## 선택지
- A. 참고 자료로 선택지 문서. 장점: OPEN 규율 유지 / 단점: 초안 재작성 필요
- B. 초안 수치를 출발점으로. 장점: 빠름 / 단점: 근거 없는 숫자가 굳음
- C. 사용 안 함. 장점: 오염 없음 / 단점: 참고 아이디어 버림

## 결정
A. 참고 자료로 선택지 문서 (추천은 A: 시뮬레이터 전에 필요한 문서이고 OPEN 규율을 지킨다.)
