# AG-P073 몸체 겹침 처리 시점

연속 가로 위치 설계에서 함께 다루길 권합니다. 곧 바뀔 차선 코드를 지금 고치지 않기 위해서입니다.

carwidth 측정에서 접촉 처리 뒤에도 몸체가 겹친 채 남는 레이스가 1500레이스 중 539~698건(36~47%)입니다. 이긴 이유 중 접촉은 0.1%라 결과 영향은 작아 보입니다. 화면이 붙으면 차가 겹쳐 보입니다. AG-P066 D로 차선 판정은 가로 위치로 바뀔 예정입니다.

## 선택지
- A. 지금 원인 측정. 장점: 겹침이 결과를 비트는지 바로 확인 / 단점: 곧 바뀔 차선 코드에 시간을 씀
- B. 가로 위치 설계에서 함께. 장점: 새 판정에서 겹침을 처음부터 막음 / 단점: 그때까지 측정 숫자에 겹침이 섞여 있음
- C. 화면 작업 때 처리. 장점: 지금 할 일이 없음 / 단점: 화면에서 문제가 늦게 드러남

## 결정
B. 가로 위치 설계에서 함께 (추천은 B: 차선 판정은 가로 위치로 갈아엎기로 했습니다. 새 판정에서 겹침을 막는 쪽이 비용이 적고, 지금 결과 영향은 작아 보입니다.)
