## 3. 식 (F-AC, 가안)

### 3-1. 식

```text
a(v) = A × (1 − c × (v / V_eff)²)
V_eff = V_top × (1 + s_ss)   (슬립스트림이 켜진 틱)
V_eff = V_top                (꺼진 틱)
```

### 3-2. 변수표

| 기호 | 뜻 | 값 · 범위 | 출처 |
|---|---|---|---|
| a(v) | 가속도 (u/s²) | v = 0이면 A. v = V_eff / √c에서 0. 그보다 빠르면 음수 | 계산 |
| v | 속도 (u/s) | 0 이상. 틱 끝 속도는 0 아래로 내려가지 않는다 | `physics.ts:131` |
| A | 가속 기본값 (u/s²) | 5점 50. 0 ~ 10점 40 ~ 60 | `config.ts:22-23`, `accelcurve.md:86-91` |
| c | 가속 곡선 계수 | 허용 값 0.5 · 0.7 (0.9는 검사 탈락, §5). 0 초과 1 미만 | `config.ts:60`, `physics.ts:46` |
| V_top | 최고속도 (u/s) | 5점 125. 100 이상 (V0 100 × (1 + 0.5 × n), n ≥ 0) | `config.ts:20-21` |
| s_ss | 슬립스트림 비율 | 0.03 (기본) | `config.ts:89` (INT §4.6 가안) |
| V_eff | 곡선 분모 속도 (u/s) | 5점 기준 켜짐 128.75, 꺼짐 125 | 계산 |

### 3-3. 기존 코드와의 관계

| 줄 | 하는 일 | 이 식과의 관계 |
|---|---|---|
| `physics.ts:45-48` | `accelDrag` 스위치. 값이 있으면 `p.drag`에 넣는다 | c가 없으면 일정 가속. 지금 `ACCEL_DRAG = 0` (`config.ts:59`) |
| `physics.ts:53` | `accelAt`: `p.drag`가 있으면 `A × (1 − drag × (v / p.vTop)²)`, 없으면 `A` | 식의 V_top 자리는 `p.vTop`이다. 이 값은 `effParams`가 준 값이다 |
| `sim.ts:717-720` | 슬립스트림 켜짐: 직선에서 `vTop × 1.03`(718), `A × 1.03`(719) | **지시서 식에는 `A × 1.03`이 없다.** 지금 코드에서 c를 켜면 "V_eff 연동 + A 증가"가 함께 적용된다 → Q-120 |

### 3-4. 퇴화 결과 (c 0.7, A 50, V_top 125 기준, 달리 적지 않으면)

| 경우 | 결과 |
|---|---|
| c = 0 | a = A. 지금의 일정 가속과 같다 |
| c ≥ 1 | 식 오류. `physics.ts:46`에서 throw한다 |
| V_top ≥ 100 | V_eff ≥ 100. 0으로 나누는 일이 없다 |
| v = V_eff | a = A(1 − c) = 15.0 (c 0.7). 수치 확인은 `accelcurve.md:90`의 V_top 근처 a = 15.0 |
| a = 0 인 속도 | v = V_eff / √c. c 0.7 → 149.4 u/s. c 0.9 → 131.8 u/s (V_eff 125 기준, 계산값) |
| c 0.9, v = 135 u/s (V_top 125 × 1.08, 부스트 8% 비교값) | a = 50 × (1 − 0.9 × 1.1664) = −2.49. 음수가 된다. c 0.9는 검사 탈락 범위라 실행 대상이 아니다 (계산값) |
| 슬립스트림이 꺼지는 순간 v = 128.75 | 식의 a = 12.9 (양수, 계산값). 그러나 `physics.ts:131`이 한 틱에 125로 깎는다. 3.75 u/s 계단. 지금 코드에도 있다 (부스트 종료도 같다) → Q-124 |

지금 실행 범위(V_top 125, 부스트 4% 구간 모드)에서는 a가 음수가 되지 않는다. 음수는 c 0.9와 부스트 8% 조합에서만 나온다.

## 4. 계산 예시 (c 0.7, A 50, V_top 125, 검산 완료)

두 해석을 나란히 적는다. 해석의 선택은 Q-120.

| v (u/s) | 앞차 a (슬립 없음) | 슬립 차 a, V_eff만 바꿈 | 차이 | 슬립 차 a, A × 1.03까지 (현재 코드) | 차이 |
|---|---|---|---|---|---|
| 77.5 | 36.55 | 37.32 | 0.77 | 38.44 | 1.89 |
| 110 | 22.90 | 24.45 | 1.56 | 25.19 | 2.29 |

- 검산 식: 앞차 50 × (1 − 0.7 × (77.5 / 125)²) = 36.55. V_eff만: 50 × (1 − 0.7 × (77.5 / 128.75)²) = 37.32. A × 1.03: 51.5 × (1 − 0.7 × (77.5 / 128.75)²) = 38.44.
- 지시서의 "약 0.8, 1.6"은 V_eff만 바꾼 해석(0.77, 1.56)과 맞는다.
- 참고: c 0이면 차이는 어느 v에서나 1.50 (= 50 × 0.03). v = 125에서 앞차 a는 15.0, 슬립 차(V_eff만)는 17.01.

## 8. 측정 계획 (AG-P044 A 형식, 가안)
