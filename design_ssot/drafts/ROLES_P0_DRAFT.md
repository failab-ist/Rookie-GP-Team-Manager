## 1. 개요

차의 제동은 "늦게 밟을 수 있는 한계"(aBrk, 차 능력치)를 정하고, 레이서의 추월은 추월 시도 중 그 한계를 "얼마나 쓰는지"(u, 레이서 능력치)를 정하는 방향을 검토한다. 이 방향과 나란히 두 안을 적는다. 하나는 시도 중 차의 한계 자체를 올리는 안(B-b), 다른 하나는 늦은 제동 없이 시도 확률만 올리는 기준안(O-c)이다. 가속은 출발과 탈출 추월(AG-P048 A)에, 집중은 실수 시간 비용(AG-P043 A)에 연결하는 안을 검토한다.

## 2. 측정 사실 (출처 포함)

### 2.1 차 : 레이서 비중

- 확인용 시드, 방향 입력 뒤: **차 : 레이서 = 100 : 0**. 레이서 0.02%, 차 8.08%(DIR:26, DIR:210-219).
- 주효과 두 개만 놓고 보면 레이서 몫은 0.25%다(계산값: 6.0 / (2405.3 + 6.0)).
- 방향 입력 전 확인용 기준선: **95 : 5**(MS:29).
- 목표는 차 7 : 레이서 3(AG-P041 A, decisions.jsonl:53). 현재 측정은 목표와 크게 다르다. 차이 계산은 §6 M-R3에서 한다.

### 2.2 제동 위주 차 최하위

- 차 5종 평균 순위(NPC 레이서)의 제동 위주 차(4/4/5/7): 조정용 **6.97**, 확인용 **6.98**. 나머지 4종은 조정용 4.63~5.99, 확인용 4.51~5.79 범위다(DIR:25). 5종 가운데 최하위다(평균 순위가 클수록 나쁘다).
- 레이서 5명 × 차 5종 표(DIR:197-204)에서도 제동 위주 열은 6.91~7.03이다(NPC 6.98).

### 2.3 출발 자리 몫

- 방향 입력 확인용: 블록 몫 73.77% 가운데 테스트 차 출발 자리 몫 **68.84%**(DIR:27, DIR:214). 입력 전 기준선은 **62.37%**(DIR:27).

### 2.4 집중 5 → 7

- 혼전 실수: 0.21 → 0.10(CTF:16, CTF:18). 평균 순위: 5.09 → 5.15(CTF:16, CTF:18).
- 실수를 만드는 코드(SIM:575-585)는 실수일 때 흔들림 배율(`MISTAKE_EPS_MUL`)만 곱한다. 속도를 깎는 항은 이 구간에 없다. 그래서 실수가 많아져도 순위 손실이 나타나지 않는다(코드 읽기, 측정 아님).

### 2.5 현행 제동 경로

- 현행 감속은 envelope 상한을 따른다: v ≤ √(vc² + 2·aBrk·d)(PHY:106, PHY:113 주석). 늦게 밟는 정도는 차 제동 능력치(B0, KB, PHY:31-35)로만 정해진다(코드 읽기, 측정 아님).
- 레이서가 제동 사용량을 정하는 입력은 현행에 없다.

## 5. 공식 (전부 가안)

### 5.1 유효 제동과 속도 상한

```text
a_eff = aBrk · u
v_cap = √(vc² + 2 · a_eff · d)
```

| 변수 | 뜻 | 범위 | 출처 / 가안 |
|---|---|---|---|
| aBrk | 차 제동 한계 감속도 (u/s²) | 0 초과 | PHY:31-35, B0·KB로 정함 |
| u | 제동 사용 배율 (1 = 현행) | O-a: 1 ≤ u ≤ u_max / O-b: u₀ ≤ u ≤ 1 | 가안, §9 |
| a_eff | 유효 제동 (u/s²) | 0 초과 | 계산값 |
| d | 코너 시작까지 거리 (u) | 0 이상 | PHY:101 |
| vc | 코너 한계 속도 (u/s) | 0 이상 | PHY:106 vCorner(p, bend) |
| v_cap | 그 지점의 속도 상한 (u/s) | vc 이상 | 계산값 |

- 퇴화 결과:
  - u = 1: 현행과 같다(PHY:106에서 aBrk를 그대로 쓴다).
  - u < 1: a_eff가 줄어 상한이 낮아진다. 같은 d에서 더 일찍 감속한다.
  - u ≤ 0: a_eff ≤ 0이 되어 √ 안이 음수가 될 수 있다. 입력을 거부한다.
  - d = 0: v_cap = vc다.
  - aBrk가 매우 작음: v_cap → vc가 된다. 늦은 제동 이득이 0에 가깝다(§7).
- 계산 예시 (가상 입력 aBrk 20, vc 10, d 10, 예시 값):
  - u = 1: √(100 + 2 · 20 · 10) = √500 = 22.4
  - u = 1.2: a_eff = 24, √(100 + 2 · 24 · 10) = √580 = 24.1
  - u = 0.8: a_eff = 16, √(100 + 2 · 16 · 10) = √420 = 20.5

### 5.2 과진입 확률과 과진입 효과

```text
p_over = clamp(k_o · max(0, u − 1), 0, 1)
과진입 시: vc ← vc · (1 − δ_o)     (그 코너, 그 추월 시도)
```

| 변수 | 뜻 | 범위 | 출처 / 가안 |
|---|---|---|---|
| u | 제동 사용 배율 | 1 ~ u_max (O-a 시도 중) | §5.1 |
| k_o | 과진입 민감도 | 0 이상 | 가안, §9 |
| δ_o | 과진입 시 코너 한계 감소 비율 | 0 이상 1 미만 | 가안, §9 |
| p_over | 과진입 확률 | 0 ~ 1 | 계산값 |

- 퇴화 결과:
  - u ≤ 1: p_over = 0이다.
  - k_o = 0: p_over = 0이다. u > 1이 비용 없이 쓰인다. 입력은 허용하고 측정에서 "비용 없음"으로 표시한다(§7).
  - δ_o = 1: vc = 0이 되어 정지한다. 입력을 거부한다.
- 계산 예시 (가안 k_o = 2):
  - u = 1.2: p_over = 2 · 0.2 = 0.4다.
  - u = 1.5: p_over = 2 · 0.5 = 1.0이다(clamp).
  - u = 1.0: p_over = 0이다.
- 과진입 효과 예시 (가상, δ_o = 0.1): vc 10 → 10 · 0.9 = 9.0이다.

### 5.3 집중 비용

```text
Δt = n_mistake · t_cost
```

| 변수 | 뜻 | 범위 | 출처 / 가안 |
|---|---|---|---|
| n_mistake | 혼전 실수 횟수 (레이스 안) | 0 이상 정수 | SIM:575-580 |
| t_cost | 실수 한 번의 시간 비용 (초) | 0 이상 | F-a에서는 t_lock, §9 |
| Δt | 집중 비용 (초) | 0 이상 | 계산값 |

- 퇴화 결과:
  - 혼전 조건이 안 됨: n_mistake = 0이다. Δt = 0이다.
  - t_cost = 0: Δt = 0이다. 현행과 같다.
- 계산 예시 (가상, t_lock 0.3 s): 실수 2회이면 Δt = 2 · 0.3 = 0.6 s다.

### 5.4 두 요인 몫

```text
몫_레이서 = SS_레이서 / SS_전체
```

- 계산 예시 (실측, 확인용, DIR:211-217): 6.0 / 29757.7 = 0.02%다.
- 퇴화 결과: SS_전체 = 0이면 '판별 불가'다.

## 6. 측정 지표 (랩타임 R 대신 레이스 효과)

공통 조건: L-B 3트랙, MOTIF_ALL, 출발 순서 10가지 × 50시드(WIN:3과 같은 구조). 판정은 확인용 시드로만 한다(RIN:484 방식).

### M-R1 순위 변화

- 정의: 레이스마다 (출발 순위 − 최종 순위)의 평균.
- 역할 효과: 역할 스위치를 켠 쌍과 끈 쌍의 차이 E_role = mean(M-R1 켠) − mean(M-R1 끈). 같은 시드·같은 출발 순서로 짝을 맞춘다.
- 계산 예시 (가상 입력): 출발 9위 → 최종 1위이면 9 − 1 = +8이다. 켠 쌍 평균 +1.2, 끈 쌍 평균 +0.9이면 E = 0.3이다.
- 퇴화 결과: 짝이 0개이면 '판별 불가'다. 역할 효과가 없으면 E = 0이다.

### M-R2 역할이 작동한 추월 수

원인 코드로는 역할을 가를 수 없다. PASS_CAUSE_ORDER는 원인 종류이고, 'brake'는 두 차 가운데 한쪽만 제동 중이어도 붙는다(SIM:301-309). '상대 실수'는 앞지른 대상의 실수다. 그래서 두 가지를 함께 쓴다.

- (가) 스위치 쌍: 역할 스위치를 켠 쌍과 끈 쌍의 추월 수 차이, 순위 차이.
- (나) 추월 기록에 붙일 표시(코드 변경은 이번 작업 범위 밖):
  - P_u: 추월한 차(passer)의 u ≠ 1 여부.
  - P_try: 추월 시도 중 여부.
  - ΔaBrk, ΔA: 두 차의 aBrk 차이, A 차이(추월한 차 − 앞지른 대상).
  - t_mist: 앞지른 대상이 자기 실수를 한 뒤 지난 시간(초).
- 역할별로 세는 것:
  - 집중: 자기 실수 뒤 T초 안에 대상이 잃은 순위(당한 쪽 기준). T = 가안 3 s(근거 없음).
  - 추월: P_u 표시가 붙은 추월의 순위 이득에서, 과진입으로 잃은 순위를 뺀 값.
  - 가속: 1랩 출발 구간 순위 변화 + ΔA > 0이고 'exit' 구간(SIM:299)인 추월 수.
  - 제동: ΔaBrk > 0이고 P_u 표시가 없는 추월 수.
- OT-4 1초 보류로 기록되지 않은 추월(WIN:8)은 M-R2에서 빼고, 따로 건수를 센다. 예: 현행 1위 변경 중 8건(WIN:28).
- 정식 추월(S1) 몫: M-R2의 추월 가운데 S1 여부로 나눈 하위 항목. 값은 §11 조건에 따른다.

### M-R3 비중

- 두 요인 분산 분석(DIR:206-219와 같은 방법). 차 주효과, 레이서 주효과, 상호작용, (트랙, 시드) 블록을 나눈다.
- 레이서 몫과 목표 30%(AG-P041 A)의 차이를 적는다: 차이 = 레이서 몫 − 30%p. 몫의 분모가 전체 분산인지 주효과 합인지에 따라 차이가 크다(Q-93).
- 현재 값(확인용, 실측): 전체 대비 0.02%, 주효과 합 대비 0.25%(계산값). 목표 30%와의 차이는 Q-93 정의에 따라 달라진다.
