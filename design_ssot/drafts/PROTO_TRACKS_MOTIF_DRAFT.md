# 1. 개요와 문제 진단

## 1.1 목적
프로토 트랙 3종의 구조를 실제 서킷의 구조(코너 순서, 직선과 코너의 비율, 헤어핀 뒤 긴 직선)에서 가져온 모티브로 다시 설계한다. 목표는 두 가지다.
1. 추월 0건을 고친다.
2. 가속력과 제동력이 순위에 실제로 작동하게 한다.

## 1.3 원인 가설 (계산으로 확인한 것과 아닌 것을 구분)
- 추월 0건: 옛 트랙 T1의 직선은 150 u다(CAR 초안 §5 표, 해당 줄 179~182). 추월 직선의 3.0 s 하한(§4.2)을 채우려면 직선 길이가 약 420 u 이상 필요하다(§5.1.2, 계산값). 직선이 짧은 것이 추월 0건의 한 원인으로 보인다. 다만 트랙 밖 원인(출발 순서, 블로킹 조건)을 배제하지 않았으므로 Q-67로 남긴다.
- 가속 R이 낮음: N1 기준 계산(§8)에서도 R = 0.11로 합격 범위(0.75~1.33) 밖이다(계산값, 근사). 긴 직선에서는 최고속도 구간이 대부분이라 가속 구간의 시간 몫이 작다. 가속이 순위에 작동하려면 가속 구간이 긴 직선이나 저속 코너 탈출이 더 많아야 한다. 이 구조 차이는 §5와 Q-65에서 다룬다.

## 1.4 이 문서가 정하지 않는 것
- 경기 길이(15 · 25 · 40 s 중 무엇인지), 모티브 선택, 게임 이름. 모두 가안이다(Q-60, Q-61, Q-63, Q-64).
- 가속 공식과 계수: 변경하지 않는다(AG-P029 A: 현행 유지, `config.ts:47`).

# 2. 플레이어 경험 (확인 가능한 형태)

플레이어가 화면이나 리플레이에서 확인할 수 있는 것만 적는다.
- E-1: 직선 한가운데서 앞차 뒤에 붙은 차가 추월 시도를 할 수 있는 직선이 트랙마다 2개 이상 있다. 각 직선에서 머무는 시간은 3.0 s 이상이다(§4.2).
- E-2: 헤어핀 뒤 직선 시작에서 가속 차이(가속 +1)가 다음 코너 진입 시점에 보인다. 기준은 직선 시작부터 최고속도 도달까지의 거리와 시간이다(§5.4).
- E-3: 3랩 합계 시간이 세 옵션(§6) 중 하나로 정해지고, 그 값이 3개 트랙에서 같은 방식으로 계산된다.
- E-4: 코너 3묶음(머리, 내부, 꼬리)이 트랙마다 있어 "같은 코너 묶음에서 속도가 이어진다"는 구간을 리플레이에서 찾을 수 있다.

# 4. 규칙 (가안)

## 4.1 공통 규칙
- R-1 코너 수: 트랙당 6~10개. N1 6, N2 8, N3 6(§5).
- R-2 코너 묶음: 묶음 머리(D > 0), 묶음 내부(D = 0), 묶음 꼬리((c) 검사). 내부 직선 길이 L_in은 다음 식을 넘지 못한다. L_in ≤ (V_c,뒤² − v_exit,앞²) / 100. 이 식은 진입 속도가 V_c,뒤를 넘지 않게 하는 상한이다(계산값, §7 예시 참고). 넘으면 그 코너는 묶음 머리가 된다(§9 E-3).
- R-3 코너 검사: CAR §4.3의 (a) Vg/bend < V_top, (b) 묶음 머리 D > 0 · 내부 D = 0, (c) L_next − D_next > 0(묶음 꼬리). k = 0과 k = 0.2 두 번 본다(§5 표).
- R-4 추월 직선: 트랙당 2개 이상. 직선 시간 T_s ≥ 3.0 s. T_s는 직선 시작에서 제동 시작까지의 시간이다(해석 1, 가안). 3.0 s는 t_lc × 3이다. t_lc = W_lane / v_lat = 4 / 4 = 1.0 s(INT §4.1, `config.ts:56~57`). 하한 3.0 s는 INT §4.3에서 가져온 값이다. 본문 대조는 아직 하지 않았다(§12).
- R-5 헤어핀 뒤 긴 직선: 트랙당 1개. 헤어핀은 bend ≥ 0.9인 코너로 본다(가안, Q-69). 헤어핀 바로 뒤 직선의 V_top 도달 거리 d_acc와 시간 t_acc를 §5에 적는다.
- R-6 직선 판정: d_acc + D ≤ L이면 V_top에 닿는다(F5). 아니면 F5-b로 계산한다.
- R-7 k 적용: 정점 뒤 한계는 min(V_top, Vg / (bend · (1 − k·s)))다. s는 정점에서 0, 코너 끝에서 1이다. 기준 k = 0.2, 확인용 k = 0이다.

## 4.2 추월 직선이 3.0 s를 채우는 조건 (계산 방법)
T_s = t_acc + t_cruise, t_acc = (V_top − v0) / A, t_cruise = (L − d_acc − D) / V_top, d_acc = (V_top² − v0²) / (2A). 기준 차에서 v0 = 92 ~ 98 u/s일 때 추월 직선 길이는 약 420 u 이상이다(계산값, §5.1 S1: L 420 → T_s 3.06 s).

# 7. 공식 (가안)

## 7.1 능력치 → 한계 값 (CAR F2, F3a, F4, F5a)

n = 능력치 / CAR_STAT_MAX(10). 각 값은 n_x로 계산한다.
- V_top = V0 · (1 + KV · n_top)
- A = A0 · (1 + KA · n_acc)
- Vg = G0 · (1 + KG · n_grip)
- a_brk = B0 · (1 + KB · n_brk)

| 기호 | 뜻 | 값 (가안) | 범위 | 출처 |
|---|---|---|---|---|
| V0 | 최고속도 기본값 | 100 | > 0 | config.ts:20 |
| KV | 최고속도 계수 | 0.5 | ≥ 0 | config.ts:21 |
| A0 | 가속 기본값 | 40 | > 0 | config.ts:22 |
| KA | 가속 계수 | 0.5 | ≥ 0 | config.ts:23 |
| G0 | 접지 기준값 | 60 | > 0 | config.ts:24 |
| KG | 접지 계수 | 0.5 | ≥ 0 | config.ts:25 |
| B0 | 제동 기본값 | 60 | > 0 | config.ts:26 |
| KB | 제동 계수 | 0.5 | ≥ 0 | config.ts:27 |

- 예시: 4능력치 모두 5(n = 0.5) → V_top 125, A 50, Vg 75, a_brk 75.
- 퇴화: V0 ≤ 0 또는 G0 ≤ 0이면 거부한다(CAR §8과 같음). KV < 0이면 거부한다.

## 7.2 코너 한계 (CAR F4와 정점 뒤 k 항)

- V_c = min(V_top, Vg / bend). 코너 bend ∈ (0.6, 1.0].
- 예시: bend 0.80, Vg 75 → V_c = 93.75 u/s.
- 퇴화: bend = 0.6이면 Vg / bend = 125 = V_top이므로 (a) "<"를 만족하지 못해 거부한다. bend = 0은 직선이며 코너 한계가 없다. bend > 1은 형식 오류로 거부한다.
- 정점 뒤 한계(F7 + k 항, 가안): 정점에서 s = 0, 코너 끝에서 s = 1로 두고 한계(s) = min(V_top, Vg / (bend · (1 − k · s)))다. k = 0이면 CAR 원형(한계 일정)이다.
- 출구 근사: v_exit = min(V_top, Vg / (bend · (1 − k)), sqrt(V_c² + 2 · A · (1 − p_apex) · L_c)). p_apex = 0.5(`config.ts:29`).
- 예시(N1-02, k = 0.2): min(125, 75 / (0.8 · 0.8) = 117.19, sqrt(8789.1 + 2000) = 103.85) = 103.85 u/s.
- 검증 예시(T1-04, 기존 트랙, CAR:160): bend 0.90, L_c 100, V_c 83.33. min(125, 75 / (0.9 · 0.8) = 104.17, sqrt(6944.4 + 5000) = 109.3) = 104.17 → 104.2. QA 실측 104.1과 0.1 차이다(반올림 · 틱 오차 범위, 계산값 대 실측).
- 퇴화: k = 0이면 출구 = V_c. k = 1이면 end 한계가 무한대가 되므로 V_top으로 자른다. k > 1이면 한계가 음수가 되므로 거부한다.
- 근사 한계: 한계가 정점과 끝 사이에서 먼저 걸리는 경우에도 끝 한계 식을 쓴다. 오차는 §9 E-7.

## 7.3 제동 거리 (CAR F5, F5-b)

- F5: D = (v² − V_c²) / (2 · a_brk). 조건: d_acc + D ≤ L(V_top 도달).
- 예시: v = 125, V_c = 93.75, a_brk = 75 → D = (15625 − 8789.1) / 150 = 45.6 u.
- F5-b (V_top에 닿지 못함): D = (V_X² + 2AL − V_c²) / (2(a_brk + A)), v_s = sqrt(V_X² + 2A(L − D)).
- 예시(N1, k = 0, 직선 N1-03 L = 120, V_X = 93.75, V_c = 78.95): D = (8789.1 + 12000 − 6233.4) / 250 = 58.2 u, v_s = sqrt(8789.1 + 100 · 61.8) = 122.3 u/s(< 125).
- 퇴화: v ≤ V_c이면 D = 0(묶음 내부). a_brk ≤ 0은 거부. D > L이면 제동이 직선에 들어가지 않으므로 거부한다.

## 7.4 직선 시간 (추월 직선 판정, 가안)

- d_acc = (V_top² − v0²) / (2A) — V_top까지 가속한 거리.
- t_acc = (V_top − v0) / A, t_cruise = (L − d_acc − D) / V_top, T_s = t_acc + t_cruise.
- 예시(N1-05, v0 = 92.10, L = 440, D = 57.9): d_acc = (15625 − 8482.4) / 100 = 71.4 u, t_acc = 0.658 s, t_cruise = (440 − 71.4 − 57.9) / 125 = 2.486 s, T_s = 3.144 s.
- 퇴화: v0 = V_top이면 d_acc = 0, t_acc = 0. T_s < 3.0이면 추월 직선 기준에 들어가지 않는다.

## 7.5 1랩 시간 (근사 모델)

- 직선 시간 = t_acc + t_cruise + t_brake, t_brake = D / ((V_top + V_c) / 2).
- 코너 시간: k = 0이면 L_c / V_c. k = 0.2이면 L_c / ((V_c + v_exit) / 2).
- 예시(N1-02, k = 0.2): 40 / ((93.75 + 103.85) / 2) = 40 / 98.8 = 0.405 s.
- 예시(1랩 합계, B): 코너 2.371 s + 직선 9.968 s = 12.339 s.
- 오차: 가속 구간의 평균 속도를 단순화했으므로 구간당 ±0.01 s 정도 오차가 있을 수 있다(근사). E와 R은 이 오차에 민감하다(§8).

## 7.6 능력치 효과 E와 R (INT §4.7)

- E = (T_orig − T_+1) / T_orig. 능력치 +1 하나만 올린 1랩 시간 차이의 비율이다.
- R = E_accel / mean(E_top, E_grip, E_brake). 합격 범위 0.75 ~ 1.33(`config.ts:123`).
- 퇴화: E_top = E_grip = E_brake = 0이면 mean = 0이므로 R은 정의되지 않는다(0 / 0). 이때 "측정 불가"로 쓰고 0으로 쓰지 않는다. E_accel = 0이고 나머지가 양수이면 R = 0이다.
- 예시: §8의 표.
