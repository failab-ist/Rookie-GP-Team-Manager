# 1. 개요와 문제 진단

## 1.1 목적

실제 서킷의 구조(코너 순서, 직선과 코너의 비율, 헤어핀 뒤 긴 직선)에서 가져온 모티브로 프로토 트랙 3종을 다시 설계한다. 이 문서가 하는 일은 다음 셋이다.

1. 모티브 후보와 근거를 적는다(§3). 선택은 USER가 한다.
2. 세 트랙의 대표 코너, 직선 구조, 코너 검사 표를 같은 식으로 계산한다(§5 ~ §7).

# 4. 규칙 (가안)

- R-1 구성: 트랙당 대표 코너 6 ~ 10개. M1 6개, M2 8개, M3 6개다(§6).
- R-2 묶음: 직선 길이 0으로 이어진 인접 코너만 묶음이다. 묶음 머리는 D > 0, 묶음 내부는 D = 0(진입 속도 ≤ V_c), 묶음 꼬리는 (c)를 통과해야 한다. 두 코너 사이 직선이 1 u 이상이면 묶음이 아니다(§9 E-6, E-10).
- R-3 코너 검사: CAR §4.3의 (a) Vg / bend < V_top, (b) 머리 D > 0 · 내부 D = 0, (c) 꼬리 뒤 직선 L − D_next > 0. 정식 검사는 F7 k = 0이다. k = 0.2 열은 참고다(§7 표 주석).
- R-4 헤어핀: V_c ≤ 50(bend 1.50)인 코너다. 트랙당 1개다. 헤어핀 뒤 직선은 Lreal ≥ 200 u인 긴 직선이어야 한다(가안).
- R-5 추월 후보 직선: 트랙당 후보를 2개 이상 표시한다. 후보의 길이와 개수는 AG-P032 실험으로 정하며(Q-70), 실험 전에는 "후보"라고만 쓴다. 추월 판정 기준 시간은 두지 않는다.
- R-6 직선 시작과 끝: 직선 시작 속도 s는 앞 코너 출구 속도, 끝 속도 e는 다음 코너 진입 속도다. 직선에서는 가속하여 V_top까지 올라갔다가 제동하며, 도달하지 못하면 피크에서 제동한다(§5.4).
- R-7 축소: 길이는 `L_i = S · ρ · Lreal_i`(직선), `L_c = ρ · Lc_real`(코너)로 쓴다(§5.3). 배율 S와 랩 길이 비율 ρ를 따로 저장한다.

# 5. 공식 (가안)

## 5.1 능력치 → 한계 값 (CAR F2, F3a, F4, F5a)

n = 능력치 / 10. 각 값은 해당 능력치의 n으로 계산한다.

- F2: V_top = V0 · (1 + KV · n_top)
- F3a: A = A0 · (1 + KA · n_acc)
- F4: Vg = G0 · (1 + KG · n_grip)
- F5a: a_brk = B0 · (1 + KB · n_brk)

| 기호 | 뜻 | 값 (가안) | 범위 | 출처 |
|---|---|---|---|---|
| V0 | 최고속도 기본값 | 100 | > 0 | `config.ts:20` |
| KV | 최고속도 계수 | 0.5 | ≥ 0 | `config.ts:21` |
| A0 | 가속 기본값 | 40 | > 0 | `config.ts:22` |
| KA | 가속 계수 | 0.5 | ≥ 0 | `config.ts:23` |
| G0 | 접지 기준값 | 60 | > 0 | `config.ts:24` |
| KG | 접지 계수 | 0.5 | ≥ 0 | `config.ts:25` |
| B0 | 제동 기본값 | 60 | > 0 | `config.ts:26` |
| KB | 제동 계수 | 0.5 | ≥ 0 | `config.ts:27` |

- 예시: 4능력치 모두 5(n = 0.5) → V_top 125, A 50, Vg 75, a_brk 75.
- 퇴화: V0 ≤ 0, G0 ≤ 0, A0 ≤ 0, B0 ≤ 0이면 거부한다. KV, KA, KG, KB < 0이면 거부한다.
- 이 절의 계수는 바꾸지 않는다(§10).

## 5.2 코너 한계와 출구 (CAR F4, F7 k = 0)

- V_c = min(V_top, Vg / bend)
- v_apex = min(v_entry, V_c)
- v_exit = min(V_c, sqrt(v_apex² + 2 · A · (1 − p_apex) · L_c)), p_apex = 0.5(`config.ts:29`). 이 기준 차에서 2A(1 − p) = A = 50이므로 v_exit = min(V_c, sqrt(v_apex² + 50 · L_c)).
- 참고 열(k = 0.2, 검사 표에만 쓴다): v_exit_k02 = min(V_top, Vg / (bend · 0.8), sqrt(v_apex² + 50 · L_c)).

| 항목 | 값 |
|---|---|
| 변수 | bend (0.6 < bend ≤ 1.5), v_entry (u/s), L_c (u), V_c (u/s) |
| 범위 | bend는 (0.6, 1.5]. 0.6 이하이면 (a)에서 실패(§9 E-1) |

- 예시(M1-C1, 기준 L-B에서 L_c = 54): bend 0.75, V_c = min(125, 75/0.75) = 100. v_entry = 100이면 v_apex = 100, v_exit = min(100, sqrt(100² + 50 · 54)) = min(100, 112.7) = 100. 참고 열: min(125, 125, 112.7) = 112.7.
- 퇴화: bend ≤ 0이면 형식 오류(거부). bend > 1.5이면 V_c < 50이므로 거부한다(헤어핀 한계 밖). L_c = 0이면 코너가 아니므로 거부한다.

## 5.3 축소: 직선 길이와 S_crit (식 A1 ~ A4)

식 A1 (길이):
- `L_i = S · ρ · Lreal_i`(직선 i). `L_c = ρ · Lc_real`(코너).
- 변수 표:

| 기호 | 뜻 | 기준 값 | 범위 (가안) | 출처 |
|---|---|---|---|---|
| S | 직선 배율 (전역) | 1.00 | (0, 2.00], 0.05 단위 | 이 문서 식 A1 |
| ρ | 랩 길이 비율 = 목표 랩 길이 / 1000 u | 1.2 / 1.8 / 2.5 | 1.0 ~ 3.0 | 축소안 §8 |
| Lreal_i | 기준 랩 1000 u에서 직선 i의 길이(실제 비율 · 가안) | 표 §7 | > 0 (0이면 묶음) | §6, §7 |
| Lc_real | 기준 랩 1000 u에서 코너 길이 | 표 §7 | 30 ~ 50 | §7 |

식 A2 (S 하한):
- V_c > V_X이면 S_b,i = (V_c² − V_X²) / (2 · A · ρ · Lreal_i) (가속 조건)
- V_X > V_c이면 S_c,i = (V_X² − V_c²) / (2 · a_brk · ρ · Lreal_i) (제동 조건)
- S_crit = max_i(S_b,i 또는 S_c,i). 직선이 없으면 S_crit = 0.
- 식 A3: S_min = (floor(S_crit / 0.05) + 1) · 0.05. 즉 S_crit보다 큰 최소 0.05 배수다. S는 S_min 이상이어야 한다(§9 E-3).

- 예시(계산 확인용): V_X = 75/0.9 = 83.33, V_c = 100, A = 50, ρ · Lreal = 100 → S_b = (10000 − 6944.4) / (2 · 50 · 100) = 0.3056. S_min = (floor(6.11) + 1) · 0.05 = 0.35.
- 퇴화: Lreal = 0은 직선이 아니라 묶음이다(S_b 계산 제외). S ≤ 0 또는 ρ ≤ 0이면 거부한다. S_crit = 0이면 0.05 이상의 모든 0.05 배수가 통과한다.

## 5.4 직선 시간 (식 A4, 근사 없음)

기준 차 값(V_top 125, A 50, a 75)으로 쓴다.

- 도달 조건: d + D ≤ L이면 V_top에 도달한다. d = (125² − s²) / (2 · 50), D = (125² − e²) / (2 · 75).
- 도달 시: t = (125 − s)/50 + (125 − e)/75 + (L − d − D)/125. 이것은 CAR F5와 같은 제동 거리다.
- 미도달 시(F5-b 동등): v_p² = 60 · L + 0.6 · s² + 0.4 · e², t = (v_p − s)/50 + (v_p − e)/75. D = (v_p² − e²)/150은 CAR F5-b의 제동 거리와 같다.
- 예시(M1-S1, 기준 L-B, L = 324, s = 62.5, e = 100): d = 117.19, D = 37.5, d + D = 154.69 ≤ 324 → V_top 도달. t = 1.25 + 0.3333 + (324 − 154.69)/125 = 2.9378 s.
- 예시(M1-S3, 기준 L-B, L = 144, s = 75, e = 50): d + D = 187.5 > 144 → 미도달. v_p² = 8640 + 3375 + 1000 = 13015, v_p = 114.09. t = (114.09 − 75)/50 + (114.09 − 50)/75 = 1.6363 s. 제동 거리 D = 70.10(CAR F5-b 식과 같음).
- 퇴화: s = 125이면 d = 0. s > e이고 L이 제동 거리보다 짧으면 v_p < s가 되어 식이 깨진다. 이 경우는 S_c 위반이므로 거부한다(§9 E-3).

## 5.5 1랩과 3랩 (식 A5)

- 1랩: T_lap = Σ(직선 t) + Σ 2 · L_c / (v_entry + v_exit). 모든 코너의 출구가 V_c이면 코너 시간은 L_c / V_c다.
- 출발 손실: 1랩의 첫 직선 S1을 정지(s = 0)에서 시작하면 추가 시간 = t(0 → e, L_S1) − t(s → e, L_S1). 이 값은 §8에 적는다.
- 3랩: T_3 = 3 · T_steady + 출발 손실(식 A5). 랩 수 3은 `config.ts:9` DEFAULT_LAPS(가안, Q-73).
- T_run: T_run = T_start + T_3 + T_result(`RACE_UNIT_LENGTH_CAMERA_P0_DRAFT.md:90` 예시, T_start 5, T_result 5, 가안, Q-75).
- 퇴화: 랩 수 0 이하는 거부한다. 랩 수 1이면 T_3 대신 T_steady + 출발 손실을 쓴다.

## 5.6 능력치 효과 E와 R (범위 밖)

E = (T_orig − T_+1) / T_orig, R = E_accel / mean(E_top, E_grip, E_brake), 합격 범위 0.75 ~ 1.33(`config.ts:123`, INT §4.7). 이 문서에서는 값을 계산하지 않는다. 축소안을 고른 뒤 Q-65에서 잰다.
- 퇴화: E_top = E_grip = E_brake = 0이면 R은 정의되지 않는다. "측정 불가"로 쓴다(0으로 쓰지 않는다).

## 8.2 S_crit과 S_min (3트랙 × 3안)

식은 §5.3(식 A2, A3)이다. 값은 ρ · Lreal을 Lb로 두고 계산했다.

| 트랙 | L-A (ρ 1.2) S_crit (직선) → S_min | L-B (ρ 1.8) S_crit (직선) → S_min | L-C (ρ 2.5) S_crit (직선) → S_min |

| M2 | 0.5813 (S4, 가속) → 0.60 | 0.3875 (S4, 가속) → 0.40 | 0.2790 (S4, 가속) → 0.30 |
| M3 | 0.7509 (S4, 제동) → 0.80 | 0.5007 (S4, 제동) → 0.55 | 0.3604 (S4, 제동) → 0.40 |
