# 1. 개요

이 문서가 정하는 것(가안):
1. 대표 코너 20개(M1 6, M2 8, M3 6)의 회전 방향 기록과 안쪽 차선 규약.
2. 트랙마다 추격 부스트 구간 Z1(가안 위치)과 2번째 후보.
3. 구간 끝 정의의 선택지(E1 · E2 · E3)와 보너스 공식 F-B1.

이 문서가 정하지 않는 것:
- 코너 우선권 규칙(AG-P036, O-001). 안쪽 차선은 우선권의 입력일 뿐이다.
- 보너스 크기 b. 범위만 쓴다(Q-83).
- 구간 수. 1 ~ 2는 범위다(Q-81).
- 게임 안 이름. 가칭 "추격 부스트"는 가칭이다(Q-84).

# 5. 공식 (가안)

## F-B1. 상한 보너스

`V_top' = V_top · (1 + b)`

| 기호 | 뜻 | 값 (가안) | 범위 | 출처 |
|---|---|---|---|---|
| V_top | 최고속도 상한(기준 차) | 125 | > 0 | MOTIF §5.1(F2, n = 0.5) |
| b | 상한 보너스 비율 | 단일 값 없음 | 0.02 ~ 0.06(가안). 0 = 효과 없음, < 0 = 거부 | 비교: INT:271 s_ss 0.03. 단일 값은 Q-83 |
| V_top' | 부스트 중 상한 | 계산값 | ≥ V_top | 이 식 |

- 계산 예시(b = 0.04, 값 아님): V_top' = 125 · 1.04 = 130.
- 계산 예시(b = 0.06, 값 아님): V_top' = 125 · 1.06 = 132.5.
- 보너스는 V_top 상한에만 걸린다. 가속 A와 제동 a_brk는 바꾸지 않는다(이 문서 범위 밖).

## F-B2. 구간 끝 E1 (고정 끝)

- L_z = L − D_base. D_base = 기준 차가 부스트 없이 제동하는 거리.
- D_base = (v_pk² − e²) / (2 · a_brk), a_brk = 75 → 분모 150. v_pk = min(125, sqrt(60 · L + 0.6 · s² + 0.4 · e²)).
- 변수: L(직선 길이, u), s(직선 시작 속도), e(직선 끝 속도 = 다음 코너 V_c), v_pk(기준 차 최고 도달 속도).
- 계산 예시(M1-S4, L-B, s = 50, e = 83.333, 값 아님): v_pk = 125(도달 확인: 60 · 468 + 0.6 · 50² + 0.4 · 83.333² = 32,358 ≥ 125² = 15,625). D_base = (125² − 83.333²) / 150 = 57.8704 u. E1 끝 = 468 − 57.8704 = 410.1296 u.
- 계산 예시(M2-S1, L-A, s = 88.24, e = 100, 퇴화 확인): v² = 60 · 108 + 0.6 · 7786 + 0.4 · 10000 = 15,152 < 15,625, 도달 실패. v_pk = 123.09. D_base = (15152 − 10000) / 150 = 34.35. L_z = 108 − 34.35 = 73.65 u. (MOTIF §7.2.2 M2-C1 L-A D 34.3과 같은 식.)

## F-B3. 구간 끝 E2 (차별 가변 끝)

- L_z' = L − D'. D' = (v'_pk² − e²) / 150, v'_pk = min(V_top', sqrt(60 · L + 0.6 · s² + 0.4 · e²)). 부스트 차마다 b에 따라 다르다.
- 아래 표의 D'는 상한이다(v'_pk = V_top' = 132.5로 계산, b = 0.06). 실제 v'_pk가 낮으면 D'는 더 작아지고 L − D'는 더 커진다. 따라서 L − D' > 0 판정은 보수적이다.

## F-B4. 구간 끝 E3 (고정 끝 + 별도 감속)

- E1의 고정 끝 뒤에 V_top으로 되돌리는 감속을 a_brk로 따로 처리한다.
- 계산 예시(M1-S4, L-B, b 0.04): 제동 시작이 E1 끝인 410.1296 u면, 130 → 83.33 감속에 66.3704 u가 필요하다. 410.1296 + 66.3704 = 476.50 > 468. 직선 안에 들어가지 않으므로 거부한다.
- 이 예시는 E3에서 거부다. E3는 제동 시작을 E1 끝(410.13 u)에 고정하므로, E2처럼 401.63 u에서 제동을 시작할 수 없다.

## F-B5. 시간 예시 (M1-S4, L-B, b = 0.04, 계산값)

- 기준 차: 가속 50에서 V_top 125까지, 끝 83.333. 직선 468 u.
- 기준 t = (125 − 50)/50 + (125 − 83.333)/75 + (468 − 131.25 − 57.8704)/125 = 1.5 + 0.5556 + 2.2310 = 4.2866 s.
- 부스트 차 t' = 1.6 + 0.6222 + (468 − 144 − 66.3704)/130 = 1.6 + 0.6222 + 1.9818 = 4.2040 s.
- 차이 = 4.2040 − 4.2866 = −0.0826 s.
- 가속 구간 144 u(= (130² − 50²) / 100), 제동 구간 66.3704 u(= (130² − 83.333²) / 150)이다.
- 이 t'는 E1과 E2에서 같다. 두 경우 모두 제동이 직선 안에서 끝난다. E3에서는 F-B4처럼 거부된다.

## 퇴화 결과

- b = 0: 효과 없음. V_top' = V_top. D' = D_base. 시간 차 0 s.
- b < 0: 입력 거부.
- L_z ≤ 0 (또는 L_z' ≤ 0): 구간 무효. 트랙 데이터 검사에서 보고한다.
- 감지 임계 ≤ 0: 입력 거부.
- e ≥ V_top': D' ≤ 0이므로 제동이 필요 없다. 끝 판정을 면제한다. 후보 7개의 e는 83.33 ~ 107.14이고 V_top' 132.5보다 작으므로 이 경우는 나오지 않는다.
- bend ≤ 0: 0 나누기 전에 거부한다(MOTIF E-2).

# 6. edge case (구체적 결과)

- E-B1 (M2 묶음 C2 → C3, 방향 전환 시 우선권): 이 문서 값은 C2 = L(안쪽 0), C3 = R(안쪽 2)이다. 승인 기획의 가정(C2 = R, C3 = L)과 반대다. 우선권은 정하지 않는다. INT:43-48은 코너 안 차선 이동을 막지 않는다고 승인 기획에 적혀 있다(확인 필요). 그래서 계산값만 적는다.
  - 묶음 통과 시간 = 63 / 83.33 + 2 · 54 / (83.33 + 98.20)(= 0.5949) = 0.7560 + 0.5949 = 1.351 s.
  - 2칸 이동 시간 = 2 · t_lc = 2 · 1.0 = 2.0 s(v_lat 4, W_lane 4, INT:127). (AG-P063 C 구간마다 폭, AG-P066 D 전환 예정, LATERAL_POSITION_WIDTH_DRAFT.md 참조)
