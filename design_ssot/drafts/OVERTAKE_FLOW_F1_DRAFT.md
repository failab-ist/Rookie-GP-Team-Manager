## §2 P-1 늦게 빠지기 (빠지기, AG-P068 A)

### 규칙

- SS-1이 켜진 채 같은 줄(같은 차선 앞차, 간격 ≤ g_ss, `config.ts:88`)에 붙어 있다가,
- 다음 제동 지점 P까지 남은 시간 t_P가 T_out 이하가 되면 옆 차선으로 빠진다. 옆 차선 표현은 AG-P066 D 전환 뒤 다시 정의한다.

지금 규칙(지난 기록)은 시도가 직선 시작에서 바로 빠지는 것이다. P-1은 그 빠지는 시점을 T_out으로 늦춘다.

### 식

```text
t_P = (L_rem − (v² − v_c²) / (2 · a_brk)) / v
빠짐 조건: t_P ≤ T_out
```

| 변수 | 뜻 | 범위 | 출처 / 가안 |
|---|---|---|---|
| L_rem | 현재 위치에서 직선 끝까지 거리 (u) | 0 이상 | 계산값 |
| v | 공격 차 속도 (u/s) | 0 초과 | 계산값 |
| v_c | 다음 코너 한계 속도 (u/s) | 0 이상 | MOTIF 직선표의 e (다음 코너 V_c) |
| a_brk | 평소 제동 가속도 (u/s²) | 0 초과 | 계산값 75 = 60 × (1 + 0.5 × 0.5) (`config.ts:26-27`, CAR F5a) |
| T_out | 빠지기까지 남은 시간 (s) | 0 초과 | 가안 2 ~ 3 s. 근거 없음 (Q-120) |

### 계산 예시

- v = 128.75 (= 125 × 1.03, 슬립스트림 s_ss 0.03, `config.ts:89`), v_c = 50, a_brk = 75이면 제동 거리 = (128.75² − 50²) / (2 × 75) = **93.8 u**.
- L_rem = 300 u이면 t_P = (300 − 93.8) / 128.75 = **1.60 s**.
  - T_out 2이면 1.60 ≤ 2이므로 빠진다.
  - T_out 1.5이면 1.60 > 1.5이므로 빠지지 않는다.

### 퇴화 결과

- v ≤ 0: 계산하지 않는다. 빠지지 않는다.
- t_P ≤ T_out(출구에서 이미 P까지 시간이 T_out 이하): 지금처럼 출구에서 바로 빠진다.
- t_P < 0(이미 제동 지점을 지남): 빠지지 않는다.
- 옆 차선이 막혀 있으면 기다린다(가안). 막힘 판정은 AG-P066 D 전환 뒤 다시 정의한다.
- T_out ≤ 0: 빠지지 않는다. 그래서 비교값에 넣지 않는다.

## §2-1 M-1 관성 (빠지기, P-1 뒤)

### 식

```text
v > V_top 이면:  v ← V_top + (v − V_top) · exp(−Δt / τ_d)
v ≤ V_top 이면:  기존 F3 (CAR:396-397)을 그대로 쓴다
```

직선에서만 쓴다. 코너에서는 기존 코너 한계가 먼저 걸린다(가안).

### 변수표

| 변수 | 뜻 | 범위 | 출처 / 가안 |
|---|---|---|---|
| Δt | 틱 길이 (s) | 0 초과 | 0.05 s (`config.ts:11`, 가안, 근거 없음) |
| τ_d | 감쇠 시간 상수 (s) | 1 ~ 4 | 가안 2 s |
| V_top | 최고속도 상한 (u/s) | CAR F2 | 기준 차 125 u/s (`CAR:373`). 실효값의 정의는 Q-98 |
| e0 | 슬립스트림이 준 초과분 (u/s) | 0 이상 | 계산값 = V_top × s_ss = 125 × 0.03 = 3.75 u/s (`config.ts:89`) |
| v | 틱 시작의 공격 차 속도 (u/s) | 0 이상 | 계산값 |

### 계산 예시

- 연속 근사: 추가 거리 = e0 · τ_d = 3.75 × 2 = **7.5 u** (τ_d 1, 2, 4에서 3.75, 7.5, 15 u).
- 처음 1초 안의 몫: e0 · τ_d · (1 − e^(−1/τ_d)) = 7.5 × (1 − e^(−0.5)) = **2.95 u** (τ_d 2).
- 틱 합(Δt = 0.05, 감쇠 계수 r = e^(−0.025) = 0.9753):
  - 순서 A (감쇠 뒤 이동): 3.75 · Δt · r / (1 − r) = **7.41 u**
  - 순서 B (이동 뒤 감쇠): 3.75 · Δt / (1 − r) = **7.59 u**
  - 구현에서 순서를 한 가지로 정하고 명시한다.

### 필요량 비교 (가정: 방어 차 속도가 그 동안 일정하다)

- 기준 3 u = L_car / 2 (`config.ts:71`). 앞 범퍼가 상대 중심을 넘는 거리다.
- **차 폭 3u 기준**: 넘어간 순간 간격 중앙값 5.07 u (`s1speed:28`). 필요량 = 5.07 + 3 = **8.1 u**. τ_d 2의 추가 거리 7.5 u는 0.6 u 모자란다 (계산값).
- **차 폭 1.9u 기준**: 넘어간 순간 간격 중앙값 4.95 u (`carwidth:139`). 필요량 = 4.95 + 3 = **7.95 u**. τ_d 2의 추가 거리 7.5 u는 0.45 u 모자란다 (계산값).
- 그래서 M-1 단독으로 중앙값 표본을 넘기기 어렵다고 본다(가설).

### 퇴화 결과

- τ_d ≤ 0: 입력 거부(지수 계산과 0 나눗셈 방지). 관성은 쓰지 않는다.
- τ_d → 0: exp(−Δt/τ_d) → 0이라 v = V_top으로 즉시 잘린다. 현행 F3과 같다.
- τ_d > 4: 가안 범위 밖이므로 입력 거부(시험하지 않는다).
- v ≤ V_top: 관성 효과 0. 기존 F3을 쓴다.
- e0 = 0(슬립스트림 꺼짐, 또는 s_ss = 0): 초과분이 없어 효과 0.

### E1 (부스트 구간 끝) 선택지

부스트 구간 끝 처리는 현행 설정에서 고정 끝 L − D_base다 (`config.ts:139`, Q-87 가안).

- (가) 부스트 구간 끝도 M-1로 처리한다. 부스트가 준 최고속도 초과분이 구간 끝에서 한 번에 잘리지 않고 같은 식으로 줄어든다. 빠지기와 같은 규칙을 쓰므로 구현이 하나로 줄어든다.
- (나) Q-87 선택지(고정 끝)를 그대로 둔다. 관성은 슬립스트림 초과분에만 쓴다.
- 연결: Q-87(구간 끝 정의), Q-80(부스트와 슬립스트림이 겹칠 때 큰 값만 쓴다. 관성의 e0 정의에 영향. `config.ts:139`).
- 추천 없음. 결정은 USER가 한다.

## §3 B-1 늦은 제동 (결판, AG-P064 B)

### 조건

- 공격 차가 자기 제동 지점 P(현행 제동을 시작하는 곳)에서 다음 코너의 안쪽 차선에 있다. 안쪽 차선 = 차선 규약 A(`config.ts:133-134`의 innerLane → 방향 칸 → DEFAULT_INNER_LANE). 차선 표현은 AG-P066 D 전환 뒤 다시 정의한다.
- 방어 차와 겹침 > 0이다(§1 나란히).
- 두 조건이 모두 참일 때만 사용률을 쓴다. 그 밖에서는 평소 제동 a_brk를 쓴다.

### 식 (하나)

```text
a_lim = a_brk · (1 + λ_max)                 차의 감속 한계 (차 제동)
a_use = a_brk + (a_lim − a_brk) · 과감성     평소 a_brk, 추월할 때 과감성만큼 a_lim 쪽으로
과감성 = 레이서 추월 / 10                    (RACER_STAT_MAX = 10, config.ts:7)
```

- 평소에는 a_use = a_brk다.
- 추월할 때는 a_use = a_brk · (1 + λ_max · 과감성)과 같다.
- 이 식이 B-1의 전부다. 옛 식(λ = λ_max × 과감성, a_late = a_brk(1 + λ))은 지난 기록이다.

### 변수표

| 변수 | 뜻 | 범위 | 출처 / 가안 |
|---|---|---|---|
| a_brk | 평소 제동 가속도 (u/s²) | B0 · (1 + kB · n_brk) | 계산값 75 (`config.ts:26-27`, CAR F5a) |
| λ_max | 차 제동의 한계 여유 비율 | 0 ~ 0.2 | 가안. 비교값 0.1, 0.2(§6 단계 3). 0.2 초과는 시험하지 않는다. 매핑은 Q-122 |
| a_lim | 차의 감속 한계 (u/s²) | a_brk 이상 | 계산값 = a_brk · (1 + λ_max) |
| 과감성 | 레이서 추월 정규화 | 0 ~ 1 | 계산값 = 추월 / 10 |
| a_use | 추월 때 쓰는 감속도 (u/s²) | a_brk ~ a_lim | 계산값 |
| h | 한계 근접도 = (a_use − a_brk) / (a_lim − a_brk) | 0 ~ 1 | 계산값 (실수 확률의 입력, Q-123) |
| h_safe | 실수가 시작되는 한계 근접도 | 0 이상 1 미만 | 가안. 근거 없음 (Q-123) |
| p0 | 실수 기준 확률 | 0 ~ 1 | 근거 없음. 비교값 0, 0.1, 0.3(§6 단계 4). Q-102 |
| δ | 실수 1회의 출구 속도 손실 비율 | 0 ~ 1 | 가안 0.1. 범위 0.05 ~ 0.2. 근거 없음 (Q-107) |
| κ | 집중이 손실을 줄이는 비율 | 0 이상 1 이하 | 가안 0.5. 근거 없음 (Q-107) |
| n_집중 | 레이서 집중 정규화 | 0 ~ 1 | 계산값 = 집중 / 10 |

### 계산표 (v = 125 → 코너 한계 50, 과감성 1일 때 값)

거리 = (125² − 50²) / (2 · a_use). 시간 t = (87.5 − 거리) / 125 + (125 − 50) / a_use. P에서 시작한 시간을 잰다. P는 현행 제동 시작점이고 P에서 코너 입구까지 87.5 u다.

| λ_max (과감성 1) | a_use = a_lim (u/s²) | 제동 거리 (u) | 코너 입구 도착 시간 t (s, P 기준) | 이득 = 50 × (1.000 − t) (u) |
|---|---|---|---|---|
| 0 | 75.0 | 87.5 | 1.000 | 0 |
| 0.1 | 82.5 | 79.5 | 0.973 | 1.36 |
| 0.2 | 90.0 | 72.9 | 0.950 | 2.5 |

- 이득은 같은 점 P에서 출발해 코너 입구에 먼저 닿는 거리다. 코너 속도 50 u/s로 환산한다.
- 계산 확인: λ_max 0.1은 (0.0636 + 0.9091) = 0.9727, λ_max 0.2는 (0.1167 + 0.8333) = 0.9500.
- **과감성 0.5, λ_max 0.2 예시**: a_use = 75 + (90 − 75) × 0.5 = **82.5 u/s²**. 제동 거리 79.5 u, 도착 0.973 s와 같다.

### 적용 비율 (제동 시작 순간 기준)

- 적용 비율은 시도 끝이 아니라 공격 차가 감속을 시작한 순간으로 잰다 (s1speed §4-1).
- 겹침 > 0 비율: **6.9%** (**3u**, `s1speed:59`, 0~3 3.9% + 3 이상 3.0%) / **7.6%** (**1.9u**, `carwidth:170`, 0~3 4.3% + 3 이상 3.3%).
- 겹침 중앙값: **−8.9 u** (**3u**, `s1speed:59`) / **−8.52 u** (**1.9u**, `carwidth:170`).
- 이득 최대 2.5 u로는 겹침을 만들 수 없다. 그래서 B-1 단독 효과는 작다고 본다(가설). M-1 등이 겹침을 먼저 만들어야 B-1이 쓰인다.

### 실수 확률 (한계에 붙은 정도로 정의)

```text
h = (a_use − a_brk) / (a_lim − a_brk)
h ≤ h_safe 이면:  p = 0
h > h_safe 이면:  p = p0 · ((h − h_safe) / (1 − h_safe))²,  [0, 1]로 자른다
```

- 계산 예시: h_safe 0.1, h 0.5, p0 0.3이면 p = 0.3 · (0.4 / 0.9)² = 0.3 · 0.1975 = **0.059**.
- 과감성 = 1이면 h = 1이고 p = p0다.
- h는 과감성과 같다(λ_max > 0일 때). 그래서 h를 따로 두는 의미가 약하다. 이 문제는 Q-123이다.
- 퇴화 결과:
  - λ_max = 0: a_lim = a_brk라 분모가 0이다. 계산하지 않고 h = 0, p = 0으로 둔다(규칙).
  - 과감성 = 0: a_use = a_brk라 h = 0, p = 0이다.
  - λ_max < 0 또는 λ_max > 0.2: 입력 거부(가안 범위 밖은 시험하지 않는다).
  - 과감성 < 0 또는 과감성 > 1: 입력 거부.
  - h_safe < 0 또는 h_safe ≥ 1: 입력 거부.
  - p0 < 0 또는 p0 > 1: 입력 거부.
  - h_safe = 0: 모든 h > 0에서 p = p0 · h²다.

### 실수 결과 1: 출구 속도 손실

```text
ΔV = v_exit · δ · (1 − κ · n_집중)
```

- 계산 예시(가상 입력): v_exit 50, δ 0.1, κ 0.5. n_집중 0.8이면 ΔV = 50 × 0.1 × 0.6 = **3.0 u/s**. n_집중 0이면 5.0, n_집중 1이면 2.5 u/s.
- 퇴화 결과:
  - κ ≤ 1이므로 (1 − κ · n_집중) ≥ 0이다. ΔV는 음수가 되지 않는다.
  - κ = 1, n_집중 = 1이면 ΔV = 0이다. 집중이 실수 비용을 전부 없앤다.
  - δ = 0이면 ΔV = 0이다.
  - κ > 1 또는 n_집중 > 1은 입력 거부.

### 실수 결과 2: 바깥 차선 밀림 (AG-P066 D 전환 뒤 다시 정의)

- 실수한 차가 바깥 차선으로 밀려 나갈 때, 바깥 인접 차선의 구간 [s − L_car, s + L_car]가 비어 있으면 그 칸으로 한 칸 민다. 인접 차선 표현은 AG-P066 D 전환 뒤 다시 정의한다.
- 방어 차가 인접 차선에 있으면 그 칸은 대개 차 있다(OT-7 판정 대상도 인접 차선이다, `sim.ts:615`).
- 방어 차가 두 칸 떨어져 있으면 비어 있을 수 있다.
- 세 번째 차가 있으면 차 있다.
- 차 있을 때의 선택지(Q-104에서 고른다):
  - (가) OT-7 패자처럼 양보한다(가안).
  - (나) 접촉 규칙(CT, AG-P039 A)으로 넘긴다.
  - (다) 밀지 않고 속도 손실만 준다.
- 퇴화 결과: 바깥 끝 차선에서는 밀 칸이 없다. 밀지 않고 속도 손실만 준다(가안, R1-5와 같은 방식).
- ROLES O-a · B-a와의 관계(Q-92)는 적기만 하고 고르지 않는다.

## §7 위험과 질문 (Q-98 ~ Q-107, Q-120 ~ Q-124. O-001 · O-002 · O-003에 연결)

- **Q-98 (O-001, 관성 기준)**: 관성의 V_top은 차 V_top(125)인지 실효 V_top(슬립스트림 · 부스트 포함, `sim.ts:697-714`)인지. 실효값을 쓰면 e0의 정의가 바뀐다.
- **Q-99 (O-001, 관성의 선두 영향)**: 선두 차에도 관성을 주면 뒤차의 막힘 상한(v_앞, INT §4.2)이 올라가 뒤차 흐름이 바뀐다. 선두에도 줄지 정한다.
- **Q-100 (O-001, 3대가 나란히 설 때)**: OT-7은 두 차만 판정한다(`sim.ts:613-615`). 3대가 같은 칸에 서면 밀림 칸 점유와 양보 순서를 어떻게 정할지 정한다. 인접 차선 표현은 AG-P066 D 전환 뒤 다시 정의한다.
- **Q-101 (나중, AG-P037 A)**: 방어 차의 늦은 제동은 이 흐름의 v0에서 다루지 않는다. AG-P037 A에 따라 기본 흐름을 확인한 뒤에 넣는다.
- **Q-102 (O-001, p0 근거 없음)**: 실수 기준 확률 p0의 값과 근거. 현재 값은 근거가 없다. 단계 4에서 0 · 0.1 · 0.3만 비교한다.
- **Q-103 (O-001, 지난 기록)**: 지난 분기 "0단계 미달이면 B-1부터 시험한다"는 AG-P068 A로 대체됐다(지난 기록). 제동 시작 순간 겹침 > 0은 **3u 6.9%**(`s1speed:59`)와 **1.9u 7.6%**(`carwidth:170`)를 나란히 쓴다. 단독 효과가 작다는 판단은 가설이다.
- **Q-104 (O-001, 밀림 대체 방식)**: 밀린 칸에 차가 있을 때 (가) 양보 / (나) 접촉 규칙으로 넘김 / (다) 속도 손실만 중 무엇을 쓸지. 현재 추천 없음.
- **Q-105 (O-001, 새 용어와 이름 충돌)**: 새 용어(붙기, 빠지기, 나란히, 결판, 기록, 관성, 늦은 제동, 과감성, 실수 비용, 겹침, 사용률, 늦게 빠지기)를 GLOSSARY에 등록할지. 이름 충돌은 다음과 같다.
  - P-1: 이 문서의 늦게 빠지기 ↔ `config.ts:52`의 P-1(가속 · 제동 1점당 비율), `LATERAL_POSITION_WIDTH_DRAFT.md:196`의 P-1(목표 띠)
  - M-1: 이 문서의 관성 ↔ `PROTO_TRACKS_MOTIF_DRAFT.md:221`의 M-1(직선 길이 0 병합 후보)
  - B-1: 이 문서의 늦은 제동 ↔ RACER 초안의 B-1(코너 설계자 배치, `RACER:293`)
  - R-1: 이 문서의 기록 ↔ `PROTO_TRACKS_DIRECTION_BOOST_DRAFT.md:47`의 R-1(차선 번호 규약)
  - 트랙 이름 M1-LB(s1cap 시드 표기, `s1cap.md:26`)와 ROLES 측정 M-R1 · M-R2(`ROLES:113`)는 이 문서에서 쓰지 않는다.
- **Q-106 (O-003, 레이서 추월의 두 쓰임)**: 레이서 추월은 INT S-A에서 시도 확률 p_try(RACER F3)에 쓰인다. 이 흐름에서는 사용률(과감성)에 쓴다. 두 쓰임을 함께 둘지 나눌지 정한다. AG-P043 A의 "추월"이 어느 쪽을 뜻하는지 확인이 필요하다.
- **Q-107 (O-002, 실수 결과의 손실 식)**: 출구 손실 ΔV = v_exit · δ · (1 − κ · n_집중)의 δ · κ 값과 근거. 현재 가안은 근거가 없다.
- **Q-92 연결 (ROLES B-a · O-a)**: 차 제동 한계 a_lim과 레이서 사용률을 묶을지(B-a). B-1의 사용률은 이 묶음과 같은 것이 아니다. 묶음 결정 뒤 다시 본다.
- **Q-120 (O-001, T_out 범위와 근거)**: 빠지기 시간 T_out의 범위와 근거. 가안 2 ~ 3 s는 근거가 없다. 단계 1에서 2와 3만 본다. 축척(초 단위)은 Q-124와 같이 본다.
- **Q-121 (O-003, 레이서 능력치 연결)**: 빠지기 시점 T_out을 레이서 능력치(예: 제어, 집중)에 묶을지. 현재 T_out은 차 · 레이서 어느 쪽에도 묶이지 않았다.
- **Q-122 (O-002, λ_max 매핑)**: 차 제동 능력치(CAR F5a, B0 · (1 + kB · n_brk))를 λ_max(0 ~ 0.2, 가안)에 어떻게 대응시킬지. 대응 식은 정하지 않는다.
- **Q-123 (O-001, 실수 확률 입력)**: h = (a_use − a_brk) / (a_lim − a_brk)가 과감성과 같아 실수 확률 식이 새 정보를 주지 않는다. 한계 근접도를 다른 식(예: 제동 거리 여유)으로 잡을지, h_safe의 근거는 무엇인지 정한다. GPT 소수 의견(`.studio/notes/안건/AG-P064.md:21`): 현재 제동력이 물리 한계인지부터 재검토하자.
- **Q-124 (O-001, 속도 · 시간 축척)**: 기하는 1u = 1m로 정했다(AG-P070 C, `decisions.jsonl:85`). 속도와 시간의 축척은 결정 대기다. 첫 단계는 고속 가속 곡선이다(AG-P072 A, `decisions.jsonl:86`). 축척 메모 참고.
