# 핸드오프: 솔브리 작업실 소개 스레드

> 스레드 글은 이 문서를 받은 세션이 쓴다. 여기에는 쓸 내용과 사실만 정리했다.

## 디렉터가 원하는 글

길게 설명하지 말고 세 마디로.

1. Claude와 GPT를 둘 다 쓰다 보니 불편해서, 이런 걸 만들었다.
2. 바탕으로 가져온 프로젝트가 MIT 라이선스여서, 그걸 가져와 우리 식으로 고쳐 달라고 했다.
3. 님들도 님들 거에 맞춰서 만들어 보셈 ㅋㅋ

말투는 가볍게, 반말 섞인 커뮤니티 톤. 기능 소개를 길게 늘어놓지 않는다.

## 왜 만들었나 (1번 재료)

- 원래 Claude(Claude Code)로 쓰고 GPT(Codex)로 검수하는 식으로 둘 다 썼다. 창을 오가며 복붙하고, 누가 뭘 했는지 기억하는 게 번거로웠다.
- 그래서 한 화면에서 같이 이야기하고, 버튼으로 결정하면, AI끼리 쓰고 검수까지 하는 작업실을 만들었다. 이름은 "솔브리 작업실"이다.

## 이렇게 생겼다 (필요하면 한두 줄만)

화면은 탭 세 개다.

- **회의**: 단톡방. 나, 프로듀서(Claude), 검토자(GPT)가 같이 있다. 그냥 쓰면 Claude가 답하고, `@GPT`라고 부르면 GPT가 답한다. `/토론 주제`를 쓰면 둘이 토론한 뒤 정리해서 올린다.
- **안건**: 회의에서 정할 게 생기면 선택지 카드로 올라온다. 나는 버튼 하나만 누른다.
- **작업**: 고른 안건이 기획, 기획 검수, 작성, 검수, QA 순서로 자동으로 진행된다. 쓰는 건 Claude, 검수는 주로 GPT가 하고, 반려되면 앞 단계로 돌아가 다시 고친다. 끝나면 [반영] 버튼 한 번에 커밋 하나로 들어간다. 푸시는 사람이 직접 한다.

이야깃거리가 될 만한 점:
- API 키를 쓰지 않는다. 이미 구독 중인 Claude Code와 Codex CLI를 그대로 불러 쓴다.
- 지난 결정과 작업은 옵시디언에서 열리는 노트로 남는다. AI는 짧은 요약만 먼저 보고 이어서 일한다.
- 화면은 전부 한국어다.

## 가져온 것과 라이선스 (2번 재료, 사실 확인 끝)

- **바탕:** [bcurts/agentchattr](https://github.com/bcurts/agentchattr) v0.5.0. 여러 AI 에이전트가 한 채팅방에서 이야기하는 로컬 채팅 서버다. MIT 라이선스, Copyright (c) 2026 Ben Curtis.
- **한 일:** 원본을 따라가지 않는 하드 포크. 채팅 화면만 살리고, AI를 실행하는 부분은 따로 만든 디스패처가 맡게 바꿨다. 보안을 조였고, 쓰지 않는 기능을 지웠고, 화면을 한국어로 바꾸고 다시 디자인했다.
- **MIT 의무:** 수정과 재배포는 자유이고, 의무는 저작권 표시와 허가문을 남기는 것뿐이다. 원본 `LICENSE`는 그대로 두었다(`ai-dev-orchestrator/ui/LICENSE`).
- 그 밖에 참고하거나 같이 쓴 것(넣을지는 작성 세션이 판단, 길어지면 빼도 된다):
  - Claude Code Game Studios (MIT, Donchitos): 프로듀서가 상의하는 방식
  - im-not-ai (MIT, epoko77-ai): 한국어 문구 다듬는 기준
  - taste-skill (MIT), impeccable (Apache-2.0): 화면 디자인 기준
  - Pretendard 글꼴 (SIL OFL 1.1)

글에서는 "agentchattr라는 MIT 프로젝트를 가져와서 내 쓰임에 맞게 고쳐 달라고 했다" 정도면 충분하다. 원작자 크레딧(저장소 링크나 이름)은 넣는 것을 권한다.

## 주의

- 저장소 `failab-ist/ai-dev-orchestrator`가 공개인지 확인하지 못했다. 링크를 넣기 전에 디렉터에게 묻는다.
- 지금 붙여 쓰는 게임 프로젝트(레이서키우기)의 기획 내용은 글에 넣지 않는다.
- 로컬 경로, 토큰, 계정 정보는 넣지 않는다.
- "AI가 알아서 다 한다"처럼 부풀리지 않는다. 결정은 사람이 버튼으로 하고, 푸시도 사람이 한다.
- 스크린샷을 붙인다면 회의 탭, 안건 카드, 작업 탭의 단계 진행 화면이 잘 보인다. 화면에 게임 기획 내용이 보이면 가린다.
- 올리기(게시)는 디렉터가 직접 한다.
